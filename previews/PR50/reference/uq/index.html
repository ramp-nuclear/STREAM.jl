STREAM.UQ — Module
STREAM.UQ

How uncertain inputs make a model's outputs uncertain.

An Uncertainty describes one input, with a systematic and a statistical part. A UQModel wraps a plain function, a compiled system at steady state, or a transient of one, and uq propagates uncertainties through it to first order. The derivatives behind that, from jacobian, come from forward-mode automatic differentiation, and a steady state is differentiated through the implicit function theorem rather than through its solver. monte_carlo samples the full model instead, for where first order is not enough.

This is Python STREAM's stream.analysis.UQ, with automatic differentiation in place of its finite differences. See Propagate input uncertainties.

STREAM.UQ.UQModel — Type
UQModel

A model's outputs as a function of some of its inputs, for uncertainty propagation. The derivatives come from forward-mode automatic differentiation (ForwardDiff), not from finite differences, so there is no step size to choose.

Build one with UQModel(f, parameters) for any function, with UQModel(ssys, op, parameters; output) for a compiled system at steady state, or with UQModel(ssys, op, parameters, t; output) for a transient. Then uq propagates Uncertaintys to the outputs to first order, jacobian gives the derivatives themselves, and monte_carlo samples the full model instead. See Propagate input uncertainties.

Fields

  • parameters: the inputs, in the order given
  • values: the nominal value of each input
  • nominal: the outputs at the nominal inputs, as one flat vector

STREAM.UQ.UQModel — Method
UQModel(ssys, op, parameters, t; output, start=:op, overrides=Pair[], solver=Rodas5P(),
        abstol=1e-8, reltol=1e-8, initializealg=nothing, steady_solver=nothing) -> UQModel

A model of a transient of a compiled system, saved at the times t.

The derivatives are carried through the integration as dual numbers, and the solver controls their error along with the values'. Where the run starts depends on start:

  • :op starts from the operating point op, as solve_transient(ssys, op, t) does.
  • :steady solves the steady state at op first and starts from it with overrides applied, as solve_transient(ssys, sol, t; overrides) does. The starting state is differentiated as in the steady UQModel, so an input moves the run both through where it starts and through what follows. An input that overrides sets acts on the steady state only.

A model with a StateMachine is not supported: its state and trip time live outside the problem, where the duals do not reach, so pass no callbacks.

Arguments

  • ssys: compiled system from mtkcompile
  • op: operating point: the start for start=:op, the steady solve's for start=:steady
  • parameters: the inputs, each a parameter of ssys
  • t: the times to save at
  • output: a function of the solution, sol -> number or array, such as sol -> sol[ssys.ch.T_out], or a vector of variables, each read as its time series
  • start: :op or :steady
  • overrides: parameter changes at t[1] for start=:steady
  • solver, abstol, reltol: for the integration
  • initializealg: DAE initialization; nothing takes NoInit() for start=:op, as solve_transient does, and BrownFullBasicInit() for start=:steady
  • steady_solver: the steady solver for start=:steady

Returns

A UQModel keyed by parameters.

Throws

  • ArgumentError: for an entry of parameters that is not a parameter of ssys, or a start other than :op and :steady
  • ErrorException: when the nominal run fails

STREAM.UQ.UQModel — Method
UQModel(ssys, op, parameters; output, solver=nothing, abstol=1e-10, reltol=1e-10) -> UQModel

A model of a compiled system at steady state.

The steady state is solved once, with solve_steady, and differentiated where it lands. With $F(u, p) = 0$ the steady equations, the implicit function theorem gives

\[du/dp = -(∂F/∂u)^{-1} ∂F/∂p\]

so the derivatives cost one linear solve, whichever steady solver found the root. output reads them off a solution whose values carry them, the same way it reads a plain one: by variable, through a ChannelState, or through any threshold correlation.

Arguments

  • ssys: compiled system from mtkcompile
  • op: operating point for the steady solve, as for solve_steady
  • parameters: the inputs, each a parameter of ssys: a design knob, or a component parameter such as ssys.pump.dP_pump. Each takes its value from op, or its default.
  • output: the outputs. A function sol -> number or array, or a vector of variables of ssys, read as sol[v].
  • solver, abstol, reltol: passed to solve_steady. The tolerances are tighter than its defaults, since the derivatives are taken at the root it returns.

Returns

A UQModel keyed by parameters.

Throws

  • ArgumentError: for an entry of parameters that is not a parameter of ssys
  • ErrorException: when the steady solve fails, or when $∂F/∂u$ is singular there

STREAM.UQ.Uncertainty — Type
Uncertainty(; systematic_relative=0.0, statistical_relative=0.0,
              systematic_absolute=0.0, statistical_absolute=0.0)

The uncertainty of one model input, as Python STREAM's Uncertainty writes it: a systematic part and a statistical part, each relative to the nominal value or absolute. An input with nominal value $x_0$ is taken to be distributed as

\[X ∼ x_0 (1 + μ_{sys,rel}) N(1, σ_{stat,rel}^2) + N(μ_{sys,abs}, σ_{stat,abs}^2)\]

The systematic part is a bias that moves every entry of a vector input together, and it propagates linearly. The statistical part is a standard deviation, independent between entries, and it propagates in quadrature. uq does both.

Each field is a number, or for a vector input a vector of its length. a + b adds the systematic parts and combines the statistical parts in quadrature.

Arguments

  • systematic_relative: bias as a fraction of the nominal value
  • statistical_relative: standard deviation as a fraction of the nominal value
  • systematic_absolute: bias, in the input's units
  • statistical_absolute: standard deviation, in the input's units

Returns

An Uncertainty.

Examples

julia> UQ.Uncertainty(statistical_absolute=3.0) + UQ.Uncertainty(statistical_absolute=4.0)Uncertainty(statistical_absolute=5.0)

STREAM.UQ.jacobian — Method
jacobian(model::UQModel) -> Matrix{Float64}
jacobian(model::UQModel, parameter) -> Matrix{Float64}

Derivatives of the outputs of model with respect to its inputs. Row i is output i of model.nominal, and the columns run over the inputs in order, one per entry of an array input. With parameter, only that input's columns, which is Python STREAM's UQModel.subjacobian.

The full matrix is computed on the first call, in one ForwardDiff pass over every input, and kept.

Arguments

  • model: the model
  • parameter: one of model.parameters

Returns

A Matrix{Float64} with a row per output.

STREAM.UQ.measurements — Function
measurements(model::UQModel, uncertainties::Pair...) -> Vector{Measurement{Float64}}

The outputs of model as Measurements.jl values, nominal ± σ, with the statistical parts of uncertainties propagated to first order. Needs using Measurements.

Each input entry becomes an independent 0 ± σ_j deviation, and output i is $y_i + ∑_j J_{ij} δ_j$. The standard deviations are those uq gives as stat, but the outputs also remember which inputs they came from, so arithmetic between them keeps their correlation: the uncertainty of y[1] - y[2] is that of the difference, not the quadrature sum of the two.

Arguments

  • model: the model
  • uncertainties: parameter => Uncertainty pairs, with no systematic part

Returns

A Vector{Measurement{Float64}}, one per output.

Throws

  • ArgumentError: for an uncertainty with a systematic part, which a Measurement cannot hold

STREAM.UQ.monte_carlo — Method
monte_carlo(model::UQModel, uncertainties::Pair...; n=1000, rng=default_rng()) -> NamedTuple

Sample the full model at inputs drawn from their uncertainties, for a check of what uq gives to first order.

Each entry of an uncertain input is drawn from the distribution Uncertainty describes,

\[X = x_0 (1 + μ_{sys,rel}) (1 + σ_{stat,rel} ε_1) + μ_{sys,abs} + σ_{stat,abs} ε_2\]

with $ε_1$ and $ε_2$ independent standard normal draws, so the systematic part shifts every sample by the same signed amount and the statistical part scatters them. The other inputs stay at their nominal values. Each sample is a full solve: of the function, of the steady state from the nominal one, or of the transient. The samples are solved on all of Julia's threads, so start Julia with --threads=auto to use them. The inputs are drawn from rng before any solve, so the result does not depend on the number of threads.

Arguments

  • model: the model
  • uncertainties: parameter => Uncertainty pairs
  • n: the number of samples
  • rng: the random number generator, for a reproducible set of draws

Returns

(; samples, mean, std, failed): the outputs of every sample, a column each, with NaN for a sample that failed to solve; the mean and the standard deviation of each output over the samples that solved; and how many did not.

Examples

julia> using Randomjulia> m = UQ.UQModel(x -> 2x.a, (a=1.0,));julia> r = UQ.monte_carlo(m, :a => UQ.Uncertainty(statistical_absolute=0.1);                          n=10_000, rng=Xoshiro(1));julia> round.(r.std; digits=2)1-element Vector{Float64}: 0.2

STREAM.UQ.uq — Method
uq(model::UQModel, uncertainties::Pair...) -> NamedTuple

Propagate input uncertainties to the outputs of model, to first order, the way Python STREAM's UQModel.uq does.

Each pair is parameter => Uncertainty(...), with parameter one of model.parameters, and an input left out has no uncertainty. With $J^{(p)}$ the Jacobian columns of input $p$, and $s^{(p)}$ and $σ^{(p)}$ its systematic and statistical parts from as_absolute,

\[s_i = ∑_p |∑_j J^{(p)}_{ij} s^{(p)}_j|, σ_i = (∑_p ∑_j (J^{(p)}_{ij} σ^{(p)}_j)^2)^{1/2}\]

Different inputs are taken as independent.

Arguments

  • model: the model
  • uncertainties: parameter => Uncertainty pairs

Returns

(; nominal, sys, stat): the nominal outputs, and their systematic and statistical uncertainties, each a vector the length of model.nominal.

Examples

julia> m = UQ.UQModel(x -> x.a + x.b, (a=2.0, b=3.0));julia> UQ.uq(m, :a => UQ.Uncertainty(systematic_absolute=1.0),                :b => UQ.Uncertainty(statistical_absolute=2.0))(nominal = [5.0], sys = [1.0], stat = [2.0])
