LocalLoss

STREAM.LocalLoss — Module
STREAM.LocalLoss

Minor (local) pressure losses across a sudden area change, after Idelchik.

factor(ṁ, A1, A2, mu) gives the dimensionless loss coefficient K, and dp turns it into a pressure in Pa. K comes from Idelchik tables 4.2 (expansion) and 4.10 (contraction), indexed by area ratio and Reynolds number, with analytic closed forms above the tabulated Reynolds range and extrapolation below it. factor is @register_symbolic, so it can sit inside an MTK equation.

The drop has the same quadratic form as Friction.darcy_weisbach_dp without the L/Dh factor. LocalPressureDrop is the component wrapping it.

source
STREAM.LocalLoss.dp — Method
dp(ṁ, rho, f, A) -> Pa

Local (minor) loss pressure drop:

\[Δp = f \, \dot{m}|\dot{m}| / (2ρA^2)\]

The same quadratic form as darcy_weisbach_dp without the L/Dh factor, because a local loss is tied to a fitting rather than to a length of duct. Positive ṁ gives a positive drop.

Arguments

  • ṁ: mass flow rate [kg/s]
  • rho: density [kg/m^3]
  • f: local loss coefficient
  • A: reference flow area [m^2]

Returns

Pressure drop [Pa].

STREAM.LocalLoss.sudden_contraction_factor — Method
sudden_contraction_factor(aratio, re) -> K

Loss coefficient for a sudden contraction from Idelchik's table 4.10 (Idelchik, 1996), as a function of the area ratio (smaller over larger) and the Reynolds number.

Above Re = 10⁴ this is the closed form 0.5·(1 - aratio)^0.75, which also replaces the table's last column so the two agree at the join, as in Python STREAM. Within the table it is a bilinear interpolation, and below Re = 10 it extrapolates.

Arguments

  • aratio: smaller area over larger, in [0, 1]
  • re: Reynolds number in the smaller section

Returns

The loss coefficient K, referred to the smaller section.

Examples

julia> LocalLoss.sudden_contraction_factor(0.3, 100.0)  # a table node
1.1

STREAM.LocalLoss.sudden_expansion_factor — Method
sudden_expansion_factor(aratio, re) -> K

Loss coefficient for a sudden expansion from Idelchik's table 4.2 (Idelchik, 1996), as a function of the area ratio (smaller over larger) and the Reynolds number.

Above Re = 3300 this is the Borda-Carnot result (1 - aratio)^2. Within the table it is a bilinear interpolation. Below Re = 10, or outside the tabulated area ratios, it extrapolates. factor is what picks between this and sudden_contraction_factor.

Arguments

  • aratio: smaller area over larger, in [0, 1]
  • re: Reynolds number in the smaller section

Returns

The loss coefficient K, referred to the smaller section.

Examples

julia> LocalLoss.sudden_expansion_factor(0.5, 1e5)  # Borda-Carnot, (1 - 0.5)²
0.25

julia> LocalLoss.sudden_expansion_factor(0.3, 100.0)  # a table node
1.2

STREAM.LocalLoss.factor — Function
factor(ṁ, A1, A2, mu) -> K

Dimensionless loss coefficient K for a sudden area change A1 -> A2, at mass flow ṁ and dynamic viscosity mu. Feed it to dp to get a pressure.

Forward flow (ṁ >= 0) goes 1 -> 2, so it sees an expansion when A2 >= A1 and a contraction otherwise. Reverse flow swaps the roles, which is what keeps the loss correct through a flow reversal.

K comes from sudden_expansion_factor or sudden_contraction_factor. It is registered with @register_symbolic, so it can sit inside a pressure-drop equation.

Arguments

  • ṁ: mass flow rate [kg/s]; its sign selects expansion or contraction
  • A1: upstream flow area [m^2]
  • A2: downstream flow area [m^2]
  • mu: dynamic viscosity [Pa·s]

Returns

The dimensionless loss coefficient K.
