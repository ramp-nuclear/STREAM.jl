## Anti-Patterns Verdict

**LLM assessment — Net: NO, with one loud regression.** Redesign has broken away from the "competent shadcn admin" silhouette. Status-bar carveout, scrimless modal lock, OKLCH layer accents, shape-coded ports, marching-ants loop trace — all read as a tool. None of the absolute bans (side-stripes >1px, gradient text, glassmorphism, hero-metric template, identical card grids, em-dashes in copy) appear.

**The regression: WelcomeOverlay.tsx is now an AI tell.** It violates the locked DESIGN.md §"First-run empty-canvas hint" doctrine: chromeless became 620×N card; no shadow became `bg-panel border rounded-md`; no wordmark became a 28 px bold `STREAM.jl` + mono `composer` subtitle; no brand mark became filter-inverted icon on a saturated navy letterhead. LLM-bootstrapped IDE splash pattern (Cursor first-run, GitHub Desktop, JetBrains Toolbox). For Marina opening the app, the brand reintroduction is patronizing.

## Overall Impression

The redesign is real and earned. Most surfaces read as a serious tool. ValidationPanel rebuild + scrimless modal lock + shape-coded ports distinguish "well-built shadcn-admin" from "well-built engineering tool." Power-user paths genuinely first-class.

Single biggest opportunity: fix WelcomeOverlay. Not a tweak — the current build implements the opposite of the doctrine the rest of Phase 72 enforced. Closing it bumps the score from 35 to ~37 and removes the loudest AI-tell on first launch.

## What's Working

1. **Severity vocabulary carve-out is correctly reasoned and correctly executed.** Icons in the status bar (compact, IDE convention), full lowercase words in the panel (compiler convention, ample space). DESIGN.md explicitly defends why the difference exists. Most tools commit to one or the other; getting both with a defensible rationale is a real design move.
2. **Port shape language earns its complexity.** Hydraulic = disc + chevron, Thermal = hexagon, BC = dashed rounded square. Color + shape + chevron-direction = three orthogonal signals encoding (layer, port-type, flow-direction). Lane 2.5 chevron desaturation (chroma 0.18 → 0.07) is the kind of small correction that separates "we colored it" from "we tuned it."
3. **Modal lock doctrine is a unique opinion.** Banning the dim grey scrim project-wide is a commitment 90% of design systems wouldn't make. `--dialog-surface` sits off the chrome/panel/canvas trio; atmospheric `--shadow-dialog` carries the lift. Dialogs read as tools placed on top of work, not interrogations.

## Priority Issues

**[P0-1] WelcomeOverlay violates locked first-run doctrine and reads as a marketing splash.**
- Where: gui/src/components/WelcomeOverlay.tsx
- Why it hurts: PRODUCT.md anti-references "AI slop" and "consumer-SaaS hand-holding"; DESIGN.md §"First-run empty-canvas hint" calls for chromeless typographic anchor. The 620×N card with navy letterhead + STREAM.jl wordmark + START/RECENT columns is precisely the LLM-bootstrapped-IDE splash pattern. For Marina (expert) the brand reintroduction is patronizing.
- Fix: Rebuild to the locked spec — chromeless 280px-wide anchor centered on canvas, no card / no border / no shadow / no wordmark / no brand mark, lowercase `recent` and `start` sections, shortcut chips as static text. DESIGN.md §5 First-run lines 771–828 are the implementation contract.
- Suggested: `/impeccable shape first-run`

**[P1-1] ValidationPanel header is 5 control elements when the panel promised "compiler output."**
- Where: ValidationPanel.tsx lines 416–497
- Why it hurts: With 1–3 issues the controls outweigh the content. Locked compiler-output silhouette gets visually contradicted by the management-widget header.
- Fix: Progressive disclosure. Hide filter pills + column-header row when count ≤ 3. Move group-by into a header overflow menu. Column headers inferable from content at small N.
- Suggested: `/impeccable polish ValidationPanel`

**[P2-1] AnatomyDialog is overbuilt for what it does.**
- Where: AnatomyDialog.tsx
- Why it hurts: 640×520 tiles with non-crossing leader proofs + numbered chips + dashed slope-2 diagonals is a diagram, not a help surface. Leader-routing engine is a long-term maintenance liability.
- Fix: Simplify to inline labels (port-name floats next to port-glyph), drop the leader system entirely. Or move to a side Sheet for scroll-through reference.
- Suggested: `/impeccable distill AnatomyDialog`

**[P2-2] WelcomeOverlay cannot be dismissed without acting.**
- Where: WelcomeOverlay.tsx
- Why it hurts: No Esc, no X. Inner panel covers canvas center where drop targets would land. Users wanting to start by dragging from toolbox can't.
- Fix: Drop on toolbox auto-dismisses; Esc dismisses; or (per spec) chromeless anchor never blocks canvas drops.
- Suggested: bundled with P0-1.

**[P3-1] Middle-dot separator (`·`) is an undeclared project idiom.**
- Where: status bar, validator chip, tooltip content, 6+ surfaces
- Why it hurts: Convention without doctrine. Either commit to `·` U+00B7 (and document/token it) or pick `/` (Linear convention for path-like) and apply uniformly.
- Suggested: `/impeccable polish` separator-idiom sweep.
