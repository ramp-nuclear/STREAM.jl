<objective>
Switch the Julia STREAM HTC pipeline so coolant fluid properties feeding `h = Nu(Re, Pr) · k / Dh`
are evaluated at the **film temperature** `T_film = (T_cool + T_wall) / 2` instead of at bulk `T[i]`.
Match Python STREAM (`heat_transfer_coefficient/__init__.py:208-209`). Preserve bulk-T evaluation for
friction Re and natural-convection Gr (both correct per Python convention).

Per D-02's "all HTC-pipeline evaluations" framing, this revision (iter 1) extends the eval-point
shift beyond the SPL/SCB equations to ALSO cover (a) the variant_obs `Nu[i]` observable in
`ChannelAndContacts` (was previously bulk; would have made `Nu[i] ≠ what h_tc[i] uses`), so the
diagnostic Nu observable stays internally consistent with the equation it diagnoses. The
`Re[i]`/`Pe[i]` observables inside `_channel_core` (line 147) DO NOT switch in this phase — see
Task 1 Edit 3 rationale (the shared core has no wall T in scope; switching there would either
require adding a wall-T parameter to `_channel_core` — touches Channel/CHF too — or branching
inside the core, both worse than leaving the core's bulk-T diagnostic alone).

where every `simple_loop` `h_tc_*[i]` row currently sits at FAIL tier (~0.18-0.20 rtol against the
0.02 hard ceiling). This phase is one of two gates on v1.1 milestone close.
