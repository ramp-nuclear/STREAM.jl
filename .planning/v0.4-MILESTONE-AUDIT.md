### Integration Findings (Non-Blocking)

1. **PHY-01 width/depth assertion gap** — `PipeGeometry_rectangular` sets `width = max(edge1, edge2)` and `depth = min(edge1, edge2)` and these are consumed correctly by Phase 14. However, the PHY-01 testset does not explicitly assert these field values. The fields are verified indirectly (Phase 14 PHY-03/04 tests use `geom.depth/geom.width`), but not directly in Phase 13.

2. **COMP helpers lack quantitative physics tests** — COMP-01/02/03/04 are verified structurally (`mtkcompile` succeeds, `unknowns > 0`), but no test solves a COMP-built system and asserts physics-correct output (e.g., temperature, mass flow). The helpers are indirectly validated by Phase 12/16 manual-wiring tests using the same underlying components.

3. **QOL-02 :mismatch branch untested** — `check_gravity_mismatch()` is implemented with both `:ok` and `:mismatch` branches, but only the `:ok` path is exercised.

4. **Phase 16 bypasses Phase 15 helpers** — VAL-01 and VAL-02 use direct `connect(...)` wiring rather than `symmetric_plate`/`plate` helpers. Deliberate (maximizes test isolation for physics validation), but means no test proves the full chain: "user calls composition helper → solver runs → result matches physics."

5. **Duplicate @testset "VAL-03"** — Two testsets share the name "VAL-03" in runtests.jl (line 361: trivial Phase 1-era placeholder; line 1068: substantive one-sided MTR test). No functional impact but produces confusing test output.
