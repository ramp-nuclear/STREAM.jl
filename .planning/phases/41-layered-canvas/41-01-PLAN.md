   ```typescript
   export function getComponentLayers(comp: ComponentDefinition): { hasFlow: boolean; hasThermal: boolean } {
     return {
       hasFlow: comp.ports.some(p => p.type === "FlowPort"),
       hasThermal: comp.ports.some(p => p.type === "ThermalPort"),
     };
   }
   ```

   - Otherwise check `getComponentLayers(comp)` -- if `activeLayer === "Hydraulic"` return `hasFlow`, if `activeLayer === "Thermal"` return `hasThermal`

   - If `activeLayer === "Both"` return `false`
   - Look up component via `getComp(componentId)`. If not found, return `false`.
   - Get layers. If `isDualLayer` (hasFlow AND hasThermal) return `false` -- per D-06 dual-layer never fully dimmed
   - If `activeLayer === "Hydraulic"` return `!hasFlow`
   - If `activeLayer === "Thermal"` return `!hasThermal`

4. `isEdgeDimmed(edgeIsThermal: boolean, activeLayer: "Hydraulic" | "Both" | "Thermal"): boolean` per D-03:
   - If `activeLayer === "Both"` return `false`
   - If `activeLayer === "Hydraulic"` return `edgeIsThermal`
   - If `activeLayer === "Thermal"` return `!edgeIsThermal`
   - Note: the caller determines `edgeIsThermal` by checking `edge.style?.stroke === "#f59e0b"` (amber = thermal edge). This keeps the utility pure.

4. Add actions (NOT undoable, NOT isDirty -- per established pattern for UI view state; but since activeLayer IS persisted, set isDirty when it changes so saves capture the preference):
   ```typescript
   setActiveLayer: (layer) => set({ activeLayer: layer, isDirty: true }),
   cycleLayer: () => {
     const order: LayerView[] = ["Hydraulic", "Both", "Thermal"];
     const { activeLayer } = get();
     const idx = order.indexOf(activeLayer);
     set({ activeLayer: order[(idx + 1) % 3], isDirty: true });
   },
   ```
