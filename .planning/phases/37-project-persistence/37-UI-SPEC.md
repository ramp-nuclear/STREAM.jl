| Label | 12px | 600 (semibold) | 1.4 |

Notes:
- Body: dropdown menu item text, recent file names in welcome overlay
- Label: keyboard shortcut hints in dropdown items (e.g., "Ctrl+S"), "No recent projects" secondary text. The 12px size at 600 weight creates sufficient visual contrast against 14px/400 body text.

## Interaction Contracts

### File Menu (D-01)

- Position: left side of toolbar, before the Code button
- Trigger: `<Button variant="outline" size="sm">` with text "File" and a ChevronDown icon (lucide `ChevronDown`, 14px)
- Dropdown: shadcn `DropdownMenu` with 4 items
- Each item shows the action label left-aligned and the keyboard shortcut right-aligned in `text-muted-foreground` at 12px
- Menu items are not disabled (New/Open/Save/Save As always available; Save on a new project behaves as Save As per D-02)

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+S | Save (or Save As if no file path) |
| Ctrl+O | Open |
| Ctrl+Shift+S | Save As |
| Ctrl+N | New project |

Implementation: global `keydown` listener in `App.tsx` (per D-11 in CONTEXT.md discretion area).

### Welcome Overlay (D-06)

- Visibility: rendered when `nodes.length === 0 && edges.length === 0`
- Position: absolute-positioned, centered on the canvas panel (not the full window)
- Layout: vertical stack — heading, optional "Recent Projects" list, "Open Project..." button
- Recent file entries: show filename only (not full path), clickable; hover state uses `bg-accent` highlight
- Max 5 entries (per D-07)
- Overlay disappears immediately when a node is added (drag from toolbox or load from file)
- No close/dismiss button — it is purely conditional on empty canvas state

### Unsaved Changes Guard (D-10, D-11)

- Trigger: window close, File > New, File > Open (when `isDirty === true`)
- Dialog: native Tauri `ask()` with title "Save changes?", message "Your project has unsaved changes that will be lost."
- Three buttons: "Save" (saves then proceeds), "Don't Save" (proceeds without saving), "Cancel" (aborts action)
- On window close: if Save chosen, save completes then `event.preventDefault()` is NOT called (window closes); if Cancel, `event.preventDefault()` keeps window open

### Error Handling (file I/O)

- All file I/O operations (`readTextFile`, `writeTextFile`, `open()`, `save()`) are wrapped in try/catch
- On failure: display native Tauri `dialog.message()` with `kind: "error"`, using the error copy from the Copywriting Contract above
- Save failure: user sees the error alert and can retry via Ctrl+S or File > Save. No data is lost (the in-memory state is unchanged).
- Open/load failure: user sees the error alert and remains on their current project (or empty canvas). No state change occurs.

### Dirty State Indicator (D-08, D-09)

- `isDirty` boolean in Zustand store
- Set `true` on: addNode, removeNode, addEdge, removeEdge, updateNodeParams, updateNodePosition, addBC, updateBC, removeBC, renameNode
- Set `false` on: successful save, successful load, new project
- Window title updated via `getCurrentWindow().setTitle()` on every `isDirty` or `currentFilePath` change

### Save/Load Serialization (D-03, D-04)

- File format: `.streamgui` extension, JSON content
- Schema: `{ version: 1, nodes: ReactFlowNode[], edges: ReactFlowEdge[], bcs: BCEntry[] }`
- NOT serialized: `selectedNodeId`, `bottomPanelOpen`, `instanceCounters` (reconstructed on load from max existing indices)
- File dialog filter: `{ name: "STREAM Composer Projects", extensions: ["streamgui"] }`
