# Phase 24.1: Bypass LOF Topology

## Why This Phase Exists

Phase 24 built a **series-loop** LOF model: Pump → Inertia → HX → ChannelHeatFlux → Flapper → back to Pump. The "flow reversal" in that model is just the Inertia coasting past zero in a single series loop — no real topology change, no junctions, no bypass. The Flapper is a series resistor that drops. This is physically wrong.

This phase replaces that model with the correct **bypass topology** that has actual junctions, a parallel path, and physically meaningful natural circulation.

---

## Agreed Topology

### Nodes

| Node | Physical location |
|------|------------------|
| A | Top of heated channel / pump outlet side |
| B | Bottom of heated channel / U-turn point |
| C | Top of return pipe = same height as A = flapper junction |
| D | Pump inlet side (after high external resistance) |

### Edges

| # | Component | Direction | Notes |
|---|-----------|-----------|-------|
| 1 | Pump + Inertia | D → A | Pump coastdown; Inertia provides hydraulic inductance (flywheel) |
| 2 | ChannelHeatFlux | A → B | Heated channel, flow nominally DOWN, gravity set to oppose downward flow |
| 3 | Channel (unheated) | B → C | Return pipe, flow nominally UP; in NC it flows DOWN (reverses) |
| 4 | Flapper | A ↔ C | Same height as A and C — no gravity term; opens at 10% of nominal mdot |
| 5 | Resistor (high R) | C → D | Represents long external piping; this is why the pump must work hard nominally |
| 6 | HeatExchanger | D → A path | Resets water temperature to T_inlet before it reaches the channel; placement right before or after the pump is equivalent (pump branch has fixed mdot direction) |

### Parallel paths between A and C

- **Long path (nominal):** A → (ChannelHeatFlux, down) → B → (return pipe, up) → C
- **Short path (bypass):** A → (Flapper) → C

---

## Expected Transient Behavior

The mass flow in the heated channel should follow this timeline:

1. **Nominal forced flow:** mdot at nominal value, channel flows downward (A→B)
2. **Pump coastdown begins:** mdot decays following the Inertia ODE
3. **Flapper opens at 10% of nominal mdot:** the bypass path A↔C opens, creating a shortcut
4. **Channel mdot drops faster:** flow prefers the low-resistance Flapper path over the channel; the channel mdot decreases rapidly
5. **mdot crosses zero:** channel flow momentarily stops
6. **Inertia overshoot into negative:** channel mdot goes negative (flow reverses to upward, B→A direction) — this requires **channel inertia** to be modeled (see requirement below)
7. **Natural circulation equilibrium:** mdot settles at a negative value driven purely by buoyancy

### Natural Circulation Driving Mechanism (confirmed physics)

After flow reversal, the inner NC loop is:
- **Hot leg (up):** B → A through the heated channel (water is heated = less dense = buoyancy drives it up)
- **Cold leg (down):** C → B through the return pipe (water was reset to T_inlet by the HX = denser = gravity pulls it down — this is the REVERSED direction for the return pipe)
- **Top connection:** A → C via Flapper (same height, zero gravity term)

This is a standard thermosyphon. The driving pressure is `rho_cold * g * H - rho_hot * g * H` = `(rho_cold - rho_hot) * g * H`. The heated channel is the hot leg; the return pipe (in NC, carrying cooled water) is the cold leg.

At NC equilibrium, the buoyancy pressure equals the friction losses in the loop. The channel temperature is hotter in NC than in forced flow (lower mdot = more heating per unit mass), which increases buoyancy drive but also increases friction per unit mass flow. These balance at the NC equilibrium mdot.

## CRITICAL New Requirement: Channel Momentum Inertia

**Status: NOT currently implemented. Must be added in this phase.**

Currently all three channel components (Channel, ChannelHeatFlux, ChannelAndContacts) have a quasi-steady pressure equation:

```
dP ~ friction(mdot) + rho * g * L
port_out.P - port_in.P ~ -dP
```

There is **no** `L/A * Dt(mdot)` inertial term. This means the channel momentum equation has no memory — it cannot produce inertial overshoot when flow reverses. Without this term, the flow reversal will be instantaneous and numerically sharp, not physical.

**Required change:** Add the momentum inertia term to `_channel_base_eqs` in `src/components/channel.jl`:

```
dP ~ friction(mdot) + rho * g * L + (geometry.L / geometry.A) * Dt(port_in.mdot)
```

Since `_channel_base_eqs` is the shared base called by Channel, ChannelAndContacts, AND ChannelHeatFlux, this single change covers all three components.

The `L/A` coefficient is available as `geometry.L / geometry.A` (PipeGeometry has both fields). The sign follows the same convention as the standalone `Inertia` component: `port_in.P - port_out.P ~ L/A * Dt(port_in.mdot)`.

**Reference:** See `src/components/misc.jl` — `Inertia` component has the identical term as a standalone element.

## Pump Model

Use the `Pump(mdot0=0) + Inertia(L_over_A=...)` pattern from phases 22-23. The Inertia ODE on the D→A branch, combined with the initial mdot condition, produces the coastdown curve. The pump has zero pressure drive (it's coasted to off). The Inertia's `L/A` parameter controls the decay timescale.

**Alternative to consider during planning:** Use `Pump(dP=dP_nominal * exp(-t/tau))` with a callable to more precisely match a coastdown curve. This may be more physical. Planner should choose based on what matches Python STREAM behavior.

**Important:** In the bypass topology, the Pump+Inertia on the D→A branch is NOT forcing a global mdot — it's one branch in a parallel network. Mdot on this branch is determined by the network pressure balance, not imposed. The Inertia just adds hydraulic inductance to that branch.

## Flapper Configuration

- Opens when `ref_mdot` (measured in the Flapper's reference branch) drops to 10% of nominal
- `threshold = 0.1 * mdot_nominal`
- Smooth ramp (Flapper's built-in C1 ramp) to avoid solver convergence issues
- Same height as A and C: `g=0.0` for the Flapper component (no gravity term needed)
- When open: low resistance (natural flow path through the bypass)
- When closed: high resistance (blocks the bypass path, all flow through channel)

---

## Gravity Sign Convention

Needs careful attention during planning. The convention in our channels: `dP ~ friction + rho * g_acc * L` where `port_out.P - port_in.P ~ -dP`.

- **ChannelHeatFlux (A→B, downward):** for a channel descending from A to B, gravity acts in the same direction as flow (helps it). Verify the sign of `g` parameter that produces physically correct behavior (pressure at B > A for static fluid). Check existing tests in `test_channel.jl` for the vertical channel convention.
- **Return pipe (B→C, nominally upward):** gravity acts against nominal flow (opposes upward flow). In NC reversed (C→B, downward), gravity assists the cold-leg descent.
