## Decisions Made
- Julia cannot dispatch on kwarg names alone (precompilation constraint). Used single outer constructor with sentinel defaults `D=nothing` / `y=nothing` and runtime branching — simpler than named factory methods, no extra types needed.
- `_channel_base_eqs` helper left unchanged — it still takes `Dh, A, L` as scalars. Channel constructors extract scalars from geometry first, then pass scalars to the helper.
- `generate_mtr_reference.py` already had `Y_LEN = 0.07` at module level; the local redefinition was removed to avoid shadowing.

## Issues Encountered
- Attempted two-separate-method outer constructors for PipeGeometry (`PipeGeometry(; L, D, A=...)` and `PipeGeometry(; L, Dh, A, y)`) — Julia precompilation rejects method overwriting for zero-positional-arg methods with only kwargs. Resolved with single-method sentinel pattern.
