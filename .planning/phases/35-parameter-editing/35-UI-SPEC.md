## Layout Contract

Primary focal point (node selected): instance name field -- full-width input at sidebar top, immediately drawing attention to the component being edited.

### Sidebar Structure (top to bottom)

```
+----------------------------------+
| Properties              [16px h] |  <- Heading, always visible
|----------------------------------|
| [empty state placeholder]        |  <- When selectedNodeId === null
|   OR                             |
| Instance Name                    |  <- Text input, Julia identifier validated
| Component Type       [badge]     |  <- Read-only, e.g. "Channel"
|----------------------------------|
| --- separator ---                |
|----------------------------------|
| Mode Toggle (Pump only)          |  <- Segmented control: fixed-dP | fixed-mdot
|----------------------------------|
| Parameters                       |  <- Section heading
|   n          [____] (Int)        |  <- Per constructorMode[activeMode].parameters
|   g          [____] m/s^2        |
|   T_wall     [____] K            |
|   ...                            |
|----------------------------------|
| Geometry (if PipeGeometry param) |  <- Section heading
| [ Circular | Rectangular ]       |  <- Segmented control
|   L          [____] m            |  <- Conditional sub-fields
|   D          [____] m            |
|----------------------------------|
| Correlations (if Function param) |  <- Section heading
|   htc_correlation  [v dropdown]  |
|   friction_corr.   [v dropdown]  |
+----------------------------------+
```

### Field Rendering Rules

| Parameter Type | Rendered As | Validation |
|----------------|-------------|------------|
| `Int` | `<Input type="text" inputMode="numeric">` | Positive integer; reject float, negative, empty, non-numeric |
| `Real` | `<Input type="text" inputMode="decimal">` | Finite number; reject NaN, Infinity, empty, non-numeric |
| `Bool` | `<Button>` toggle (on/off) | Always valid |
| `PipeGeometry` | Segmented control + conditional sub-fields | All sub-fields required and positive |
| `Function` | `<Select>` dropdown from registry `options` | Selection always valid; factory items disabled |
| `Matrix` | `<Badge variant="secondary">` read-only: "nz x nx matrix" | Not editable in GUI (requires code) |

### PipeGeometry Sub-Fields

| Geometry Type | Fields | Units |
|---------------|--------|-------|
| Circular | L (Real, m), D (Real, m) | Length, Diameter |
| Rectangular | L (Real, m), W (Real, m), H (Real, m) | Length, Width, Height |

Switching type clears all dimension fields to empty (D-02).

### Pump Mode Toggle

| Mode | Visible Parameters | Hidden Parameters |
|------|-------------------|-------------------|
| fixed-dP | dP_pump (Pa) | mdot0 |
| fixed-mdot | mdot0 (kg/s) | dP_pump |

Mode toggle is a segmented control identical in style to PipeGeometry picker. Default mode: fixed-dP.

## Interaction Contract

### Selection Flow
1. User clicks canvas node -> `selectNode(nodeId)` fires -> sidebar renders form for that node
2. User clicks canvas background -> `selectNode(null)` fires -> sidebar shows empty state
3. User clicks different node -> sidebar immediately updates to new node's form (no transition animation)

### Validation Behavior
- Fires on blur (D-06), not on keystroke
- Error message appears directly below the field in destructive color
- Invalid field input border changes to `--destructive`
- Submitting/storing: invalid values are NOT written to store; the previous valid value is retained

### Rename Behavior
- Instance name field at top of sidebar
- On blur: validate against `^[a-zA-Z_][a-zA-Z0-9_]*$`
- On valid: `updateNodeParams(nodeId, { instanceName: newName })`
- On invalid: show error "Must be a valid Julia identifier (letters, digits, underscores; must start with a letter or underscore)"
- Canvas node label updates immediately via store subscription

### Unit Display
- Units rendered as suffix text inside the input container, right-aligned
- Uses muted-foreground color at Label size (13px, weight 600)
- Not interactive; purely informational
