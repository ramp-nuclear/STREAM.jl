```julia
function Pump(dP_pump::Real; name)
    pars = @parameters dP_pump = dP_pump
    @named port_in  = FlowPort()
    @named port_out = FlowPort()
    eqs = Equation[
        port_in.mdot + port_out.mdot ~ 0,
        port_out.P - port_in.P ~ dP_pump,
        port_out.T ~ instream(port_in.T),
        port_in.T  ~ instream(port_out.T),
    ]
    compose(System(eqs, t, [], pars; name=name), port_in, port_out)
end
```

Create `src/components/flapper.jl` with a single function `Flapper(; name, dt=5.0, threshold=0.01, R_closed=1e8, R_open=100.0)` that returns an uncompiled MTK System. The function must:

1. Declare parameters via `@parameters`:
   - `dt = dt` (ramp duration, seconds)
   - `threshold = threshold` (ref_mdot threshold, kg/s)
   - `R_closed = R_closed` (closed resistance, Pa*s/kg)
   - `R_open = R_open` (open resistance, Pa*s/kg)

2. Declare variables via `@variables`:
   - `T_open(t) = 1e30` -- differential state, sentinel value (NOT Inf per research -- Inf crashes Rodas5P). Per D-01/D-02/D-03, this is a state var with Dt(T_open) ~ 0, mutated by the continuous event.
   - `xi(t)` -- ramp fraction (0 to 1)
   - `ref_mdot(t)` -- trigger variable, NO equation inside Flapper (per D-04/FLAP-04, user wires it externally)

3. Create FlowPorts: `@named port_in = FlowPort()`, `@named port_out = FlowPort()`

4. Create the SymbolicContinuousCallback:
   ```julia
   using ModelingToolkit: SymbolicContinuousCallback
   cb = SymbolicContinuousCallback(
       [ref_mdot - threshold ~ 0],
       nothing;
       affect_neg = [T_open ~ t]
   )
   ```
   - `nothing` for affect (ignore upward crossing)
   - `affect_neg = [T_open ~ t]` fires on downward crossing (ref_mdot drops below threshold)
   - Per D-06, this latches open -- no re-close event

5. Build equations (Equation[] array):
   - `port_in.mdot + port_out.mdot ~ 0` (mass conservation)
   - `D(T_open) ~ 0` (holds T_open constant until event fires, per D-02)
   - `xi ~ clamp((t - T_open) / dt, 0.0, 1.0)` (ramp fraction, per FLAP-02; clamp works natively in MTK per research)
   - `port_in.P - port_out.P ~ (R_closed + (R_open - R_closed) * (3*xi^2 - 2*xi^3)) * port_in.mdot` (pressure drop with Hermite cubic interpolation per FLAP-02, per D-08 pure dP check valve)
   - `port_out.T ~ instream(port_in.T)` (temperature passthrough)
   - `port_in.T ~ instream(port_out.T)` (temperature passthrough)

6. Return: `compose(System(eqs, t, vars, pars; name=name, continuous_events=[cb]), port_in, port_out)`

Add a docstring before the function with:
- Description: Flapper check-valve component with continuous event trigger
- Note that T_open uses 1e30 sentinel (not Inf) to avoid stiff solver instability
- Note that ref_mdot must be wired externally via `flapper.ref_mdot ~ component.port_in.mdot`
- `# Arguments` section listing all keyword args with units and defaults
- `# Ports` section: port_in, port_out (FlowPort)
- `# Returns` section: Uncompiled System

Use `D = Differential(t)` at module level (or inside function) -- check how pump.jl accesses it (MTK provides `D` via `ModelingToolkit`; the project uses `Dt` from the module -- verify by checking if other components use `D(T_open)` or `Dt(T_open)` syntax).
