# Phase 33 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (initialize during scaffold setup) |
| Preset | Default — `npx shadcn@latest init` with New York style, Zinc base color, CSS variables enabled |
| Component library | Radix (via shadcn/ui) |
| Icon library | lucide-react |
| Font | Inter (system fallback: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif) |

**Note:** `gui/` does not exist yet. Phase 33 creates the Tauri 2 app from scratch. shadcn must be initialized as part of scaffold setup so that all subsequent phases (34-40) can use shadcn/ui primitives from day one. DSGN-01 requires shadcn/ui for all UI primitives. Deferring initialization to Phase 38 would force Phase 34-37 to use raw HTML elements and then rewrite them — wasteful. Initialize early, use throughout.

**shadcn init command** (run after `npm create tauri-app` and `cd gui`):
```bash
npx shadcn@latest init -d
```
Then confirm `components.json` exists and `npx shadcn info` reads correctly.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, toolbox item padding |
| md | 16px | Default element spacing, panel inner padding |
| lg | 24px | Section padding, panel header height padding |
| xl | 32px | Layout gaps between panels |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (unused in Phase 33) |

Exceptions: Touch targets for toolbox items must be at minimum 36px height (desktop app, not mobile — 44px not required).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 500 (medium) | 1.4 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

**Rationale:** 14px body is standard for desktop tool UIs (VS Code, Figma, engineering tools). 12px labels for compact panel content. 3 weights declared (400, 500, 600) — medium weight used only for labels to differentiate from body text without resorting to bold.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(0 0% 100%)` / `hsl(240 10% 3.9%)` (dark) | Background, canvas area, main surfaces |
| Secondary (30%) | `hsl(240 4.8% 95.9%)` / `hsl(240 3.7% 15.9%)` (dark) | Toolbox panel bg, sidebar panel bg, card surfaces |
| Accent (10%) | `hsl(240 5.9% 10%)` / `hsl(240 4.8% 95.9%)` (dark) | See reserved list below |
| Destructive | `hsl(0 84.2% 60.2%)` | Delete node, delete edge, destructive confirmations only |

**Color mode:** Follow system preference via `prefers-color-scheme`. shadcn/ui Zinc palette provides both light and dark tokens out of the box.

Accent reserved for:
- Selected node highlight ring on ReactFlow canvas
- Active/selected toolbox item indicator
- Primary action buttons (future phases: "Export", "Save")
- Focus rings on form inputs (future Phase 35)

## Layout Contract (Phase 33 Specific)

Phase 33 creates the three-panel shell layout. This section defines the structural contract.

| Panel | Position | Default Width | Collapsible | Phase 33 Content |
|-------|----------|---------------|-------------|------------------|
| ToolboxPanel | Left | 240px | Yes (to 0px) | Empty shell with heading "Components" |
| CanvasPanel | Center | Remaining (flex: 1) | No | ReactFlow with empty canvas, zoom/pan/minimap |
| SidebarPanel | Right | 320px | Yes (to 0px) | Empty shell with heading "Properties" |

**Panel boundaries:** 1px border using `border` token from shadcn theme (not a custom color).

**Canvas background:** ReactFlow default dot grid pattern. No custom background in Phase 33.

**Minimum window size:** 800x600px. Panels collapse gracefully below 1200px width (toolbox auto-collapses first, then sidebar).

## Component Inventory (Phase 33)

Phase 33 renders minimal UI. Components needed from shadcn/ui:

| shadcn Component | Used For | Phase |
|------------------|----------|-------|
| (none installed in Phase 33) | — | — |

**Rationale:** Phase 33 creates unstyled panel shells with basic HTML/CSS structure. shadcn is *initialized* (components.json, Tailwind config, CSS variables) but no shadcn components are installed yet. Phase 34 will install the first components (Button, ScrollArea, Tooltip) when building the toolbox. This avoids installing components speculatively.

**Alternative considered:** Pre-installing Button, Card, ScrollArea. Rejected because Phase 33 scope is explicitly "unstyled shells" per CONTEXT.md D-06. Installing components without using them adds dead code.

## Phase 33 Interaction Contract

Phase 33 has minimal interactions. Documenting what DOES and DOES NOT exist at phase end:

**Does exist:**
- ReactFlow canvas with zoom (scroll wheel), pan (click-drag), minimap overlay, fit-to-view control
- Three-panel layout with panel boundaries visible
- App window launches via `npm run tauri dev`

**Does NOT exist (deferred to later phases):**
- Dragging components from toolbox (Phase 34)
- Node rendering on canvas (Phase 34)
- Parameter editing sidebar content (Phase 35)
- Any buttons, forms, or interactive widgets beyond ReactFlow built-in controls
