<objective>
Land the 4-layer Tauri foundation required by the custom titlebar: install `@tauri-apps/plugin-os` and register `tauri-plugin-os` at every layer (npm + Cargo + Rust builder + capability permissions), set `decorations: false` on the main window, and copy the app icon into a Vite-reachable location. Per RESEARCH.md, this 4-layer registration is the dominant risk in the phase — missing any one layer produces silent IPC no-ops with no console error. Isolating it in Wave 1 lets the executor verify the build before downstream UI components reference the plugin.

Purpose: De-risk the silent-failure surface. Without `core:window:allow-minimize` and friends, every WindowControls button will render but do nothing. Without `decorations: false`, the OS chrome will remain on top of the custom titlebar.
Output: A buildable Tauri app with OS chrome removed, OS plugin registered end-to-end, capability permissions in place, and a Vite-reachable app icon.
</objective>
