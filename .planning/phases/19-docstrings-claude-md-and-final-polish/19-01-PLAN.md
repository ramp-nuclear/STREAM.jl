**channel.jl -- Channel:**
- Signature: `Channel(; name, n, geometry, g=0.0, htc_correlation=dittus_boelter, friction_correlation=blasius_friction)`
- Description: "Single-phase convective channel with `n` axial finite-volume cells."
- Arguments: `name` (Symbol), `n` (number of axial cells), `geometry` (PipeGeometry), `g` (gravitational acceleration [m/s^2], 0.0 for horizontal), `htc_correlation` (HTC function `(Re,Pr)->Nu`, default `dittus_boelter`), `friction_correlation` (friction function `(Re)->f`, default `blasius_friction`)
- Ports: `port_in`, `port_out` (FlowPort); `thermal` (ThermalPort -- single scalar wall temperature BC)
- Place the docstring before the line `function Channel(; name, n::Int, geometry::PipeGeometry, g = 0.0,` (NOT before the `function Channel end` forward declaration on line 4)

**pump.jl -- Pump:**
- Signature: `Pump(; name, dP_pump=nothing, mdot0=nothing)`
- Description: "Fixed-pressure-drop or fixed-mass-flow pump. Exactly one of `dP_pump` or `mdot0` must be provided."
- Arguments: `name` (Symbol), `dP_pump` (fixed pressure rise [Pa], or `nothing`), `mdot0` (fixed mass flow rate [kg/s], or `nothing`)
- Ports: `port_in`, `port_out` (FlowPort)
- Note in description: errors if both or neither kwarg is provided

- Signature: `Friction(; name, L, D, A)`

- Ports: `port_in`, `port_out` (FlowPort)

- Ports: `port_in`, `port_out` (FlowPort)

**resistors.jl -- Resistor:**

- Arguments: `name` (Symbol), `R` (resistance coefficient [Pa/(kg/s)])
- Ports: `port_in`, `port_out` (FlowPort)

- Ports: `port_in`, `port_out` (FlowPort)

- Ports: `thermal` (ThermalPort -- single port, used as a wall BC)

- Description: "Check whether gravity pressure contributions in a hydraulic loop are balanced."

- Signature: `plate(ch_left, ch_right, fuel; name) -> ODESystem`
- Description: "Wire a `HeatDiffusion` fuel plate between two `ChannelAndContacts` channels (left and right faces)."
- Arguments: `ch_left` (uncompiled ChannelAndContacts for left face), `ch_right` (uncompiled ChannelAndContacts for right face), `fuel` (uncompiled HeatDiffusion), `name` (Symbol)

- Arguments: `channel` (uncompiled ChannelAndContacts), `fuel` (uncompiled HeatDiffusion), `side` (`:left` or `:right`, which face of the fuel plate connects to the channel), `name` (Symbol)
- Returns: "Uncompiled `ODESystem` from `compose()`."

**helpers.jl -- compose_systems:**
- Signature: `compose_systems(systems...; connections, name) -> ODESystem`
- Description: "Compose multiple MTK systems with explicit connection equations into a single system."

- Returns: "Uncompiled `ODESystem` ready for `mtkcompile()`."

**solvers.jl -- steady_state_guess:**
- Signature: `steady_state_guess(; T_inlet, Q_wall, mdot_guess, n) -> Vector{Float64}`
- Description: "Generate a linear temperature guess for steady-state initialization."
- Arguments: `T_inlet` (inlet temperature [K]), `Q_wall` (total wall heat input [W]), `mdot_guess` (estimated mass flow rate [kg/s]), `n` (number of axial cells)
- Returns: "Vector of length `n` with linearly interpolated temperatures from `T_inlet` to estimated `T_outlet`."

**solvers.jl -- solve_steady:**
- Signature: `solve_steady(ssys, op; solver=nothing, kwargs...) -> SciMLSolution`
- Description: "Solve a compiled system to steady state using KINSOL (or a user-specified solver)."
- Arguments: `ssys` (compiled system from `mtkcompile`), `op` (operating point as `Vector{Pair}` of initial guesses), `solver` (nonlinear solver, default `nothing` which selects KINSOL), `kwargs...` (additional keyword arguments forwarded to `solve`)
- Returns: "`SciMLBase.NonlinearSolution`. Access results via `sol[ssys.component.variable]`."

**solvers.jl -- solve_transient:**
- Signature: `solve_transient(; ssys, T_wall_sym, op, tspan, T_wall_transient, solver=nothing, kwargs...) -> SciMLSolution`
- Description: "Solve a transient simulation with a time-varying wall temperature callback."
- Arguments: `ssys` (compiled system), `T_wall_sym` (symbolic parameter for wall temperature), `op` (initial operating point as `Vector{Pair}`), `tspan` (time span tuple `(t_start, t_end)` [s]), `T_wall_transient` (function `t -> T_wall(t)` [K]), `solver` (ODE solver, default `nothing`), `kwargs...` (forwarded to `solve`)
- Returns: "`SciMLBase.ODESolution`. Access time-dependent results via `sol[ssys.component.variable]`."
