## Tests

### 1. All HTC correlation options are selectable
expected: Open a Channel (or ChannelAndContacts / ChannelHeatFlux) node sidebar. The "htc_correlation" dropdown shows 5 options: Dittus-Boelter, Constant Nusselt, Regime Dependent, Elenbaas, Maximal HTC — none grayed out or disabled.
result: pass

### 2. Regime Dependent shows 3 sub-fields
expected: Select "Regime Dependent" from htc_correlation. Immediately below the dropdown, an indented sub-field group appears (left border) with: a "htc_forced" dropdown, a "htc_natural" dropdown, and a "threshold" numeric input pre-populated with 1.0.
result: pass

### 3. Elenbaas shows 4 numeric sub-fields
expected: Select "Elenbaas" from htc_correlation. 4 numeric fields appear below: b, L, Dh, g — where g is pre-filled with 9.80665. The other three are empty.
result: pass

### 4. Maximal HTC shows 2 sub-dropdowns
expected: Select "Maximal HTC" from htc_correlation. 2 sub-dropdowns appear: htc1 and htc2. Each shows simple closure options only (Dittus-Boelter, Constant Nusselt) — no factory options inside.
result: pass

### 5. Sub-fields reset when switching factories
expected: Select "Regime Dependent", set threshold to 0.5. Then switch to "Elenbaas". The regime_dependent sub-fields disappear and Elenbaas sub-fields appear fresh (empty, not carrying the 0.5 over). Switch back to "Regime Dependent" — threshold is blank/default, not 0.5.
result: pass

### 6. Nested elenbaas inside Regime Dependent
expected: Select "Regime Dependent". In the htc_forced sub-dropdown, select "Elenbaas". A second-level indented group appears below htc_forced with 4 numeric inputs: b, L, Dh, g. The htc_natural dropdown and threshold field remain visible alongside it.
result: pass

### 7. Info icons on numeric field labels
expected: In any Channel node sidebar, each numeric parameter label (e.g. n, g, L, Dh) has a small ⓘ icon to the right of the text. Hovering over ⓘ next to "g" shows tooltip: "Gravitational acceleration; 0.0 for horizontal, 9.80665 for vertical" (or similar description).
result: pass

### 8. Info icons on geometry picker fields
expected: In the Geometry section of a Channel node sidebar, the dimension labels (L and D for circular; L, W, H for rectangular) each have an ⓘ icon. Hovering shows a short description (e.g. "Channel length", "Inner diameter").
result: pass

### 9. Name label and info icon on instance name field
expected: The instance name input at the top of the sidebar now has a "Name" label above it with an ⓘ icon. Hovering shows: "Julia variable name for this component in generated code".
result: pass
