# Phase 35.1 Plan 3: Info Icons — Retrofit All Sidebar Field Labels Summary

**One-liner:** Added Info icon + shadcn Tooltip to all remaining sidebar field labels (NumericField, PipeGeometryPicker, InstanceNameField).

## What Was Built

Three sidebar components now display a small Info icon next to their field labels. Hovering shows a tooltip with a description. This completes the info-icon retrofit across all sidebar field types started in Plan 2.

- **NumericField**: Label gets `flex items-center gap-1` + conditional `<Info>` icon wrapped in `TooltipProvider`; icon shown only when `param.description` is non-empty.

- **InstanceNameField**: Added `Label` import plus `Info`/Tooltip imports; label "Name" with unconditional Info icon and hardcoded description "Julia variable name for this component in generated code" added above the Input.
