5. `laminar_friction(; aspect_ratio::Real)` — factory. Precomputes `k_R = rectangular_laminar_correction(aspect_ratio)` at construction time. Returns `(Re) -> 64.0 / (Re * k_R)`. The aspect_ratio kwarg is REQUIRED (no default) — callers must be explicit.

   ```julia
   (
     htc      = (Re, Pr) -> ifelse(Re < Re_tr, htc_laminar(Re, Pr), htc_turbulent(Re, Pr)),
     friction = (Re)     -> ifelse(Re < Re_tr, friction_laminar(Re), friction_turbulent(Re))
   )
   ```
   Uses `ifelse()` (NOT if/else) — established project pattern for MTK-compatible smooth switching.
