<sanitization_requirements>
Filename sanitization rules — apply IN ORDER:

1. Trim leading/trailing whitespace (`name.trim()`).
2. Strip the OS-illegal characters: `/ \ : * ? " < > |` AND control
   characters (`\x00-\x1f`). Replace each with empty string.
   Regex: `[\\/:*?"<>|\x00-\x1f]`. Use the `g` flag.
3. Collapse runs of internal whitespace to a single space (cosmetic;
   prevents `"my   project"` becoming `"my   project.scp"` with three
   spaces in the OS dialog).
4. Trim again after sanitization (the strip could leave leading/trailing
   spaces if the user typed something like `" my:project "`).
5. If the result is empty → return `"project.scp"`.
6. If the result already ends with `.scp` (case-insensitive) → return
   the result (do NOT append).
7. Otherwise → return `result + ".scp"`.

DO NOT lowercase the name. DO NOT remove unicode characters that are
filename-legal on the underlying OS (the OS dialog handles unicode
correctly on Windows / macOS / Linux). DO NOT enforce Julia-identifier
rules — `modelOptions.name` is a free-form project label per Plan
62-07's "Project Name is a free string, not a Julia identifier" note.
</sanitization_requirements>
