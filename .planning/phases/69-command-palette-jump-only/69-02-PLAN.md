    1. **Conditional mount** — if `!open`, return `null`. Per Pitfall 8 (RESEARCH.md), this prevents the search pool from rebuilding on every node drag while the palette is closed. App.tsx (Plan 03) renders this component unconditionally; the early `return null` is the optimization.

       - `component` branch: read `getComponentLayers(item.comp)`; for each `k` where `!activeLayers[k]`, call `setLayerVisible(k, true)`. Then `setCenter(item.node.position.x, item.node.position.y, { zoom: Math.max(getZoom(), ZOOM_MIN_LEGIBLE), duration: 250 })`. Then `selectNode(item.id)`. Then `onOpenChange(false)`.        - `geometry` / `powerShape` / `fluid` branch: `setActiveLeftTab("Resources"); selectResource(item.uuid, item.kind); onOpenChange(false); setSearch("");`
       - `modelOptions` branch: `setActiveLeftTab("Project"); clearSelection(); onOpenChange(false); setSearch("");`

       ```tsx
               {search.length === 0 ? <BrowseGroups items={items} ... /> : <FlatList items={items} ... />}
             </CommandList>
           </Command>
         </DialogContent>
       </Dialog>
       ```

    8. **BrowseGroups + FlatList helpers** (local sub-components inside the file, not separate files):
       - `BrowseGroups`: render one `<CommandGroup heading="Components">` per non-empty kind, ordered Components, Geometries, Power Shapes, Fluids, Project. Each row uses the `renderItem(item)` helper.

       - `modelOptions`: `<CommandItem value="Project Options Model Options" onSelect={() => handleSelect(item)}>` (the extra "Model Options" tokens in the value give cmdk extra matchable terms so the user can type "model" and hit it) with `Settings2` icon and label "Project Options".

    10. **No matched-character highlighting** (D-07) — render names as plain text. Do NOT pass the search query down to render-time highlight logic.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Search query string → cmdk filter | User input is treated as a literal scoring token; cmdk's command-score never evaluates it as code. No mitigation needed beyond TypeScript's type system. |
