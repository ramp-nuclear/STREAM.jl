<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-controlled file path → getSidecarBasename → filesystem write path | A malicious or weird filename (e.g. `../../etc/passwd.scp`) could traverse out of the autorecover directory if not sanitized. **MITIGATE.** |
| `running.lock` file contents → parseLockfileContent → isPidAlive(pid) | Corrupted lockfile (manual edit, partial write, garbage) could lead to PID-alive checks on absurd inputs. **MITIGATE.** |
| Tauri command `is_pid_alive` exposed surface | Anyone with access to the IPC channel can query whether arbitrary PIDs are alive. **ACCEPT** (local-only IPC; not a leak of meaningful information). |
