<objective>
Ship three geometry / shape validators per D-15 (§3.9 rules 1, 2, 9): z_N match, length match, geometry consistency across shared coupling. Each rule emits a FixAction per the §3.9 assignment (lossless-sync, value-transfer-picker, navigation-only respectively).

Purpose: catch dimensional inconsistencies between thermally-coupled components (CAC ↔ HD ↔ Plate) before the user exports — these are the most common Julia-side runtime errors users hit in v0.8. The FixAction buttons reduce a multi-click navigate-and-edit flow to a single click for the lossless cases.

Output: three pure-function Validator modules (each emitting a FixAction per §3.9) + tests + registry append.
</objective>
