# Phase 63.1 Plan 06: BCs tab body — Anchors section (sidebar UI) Summary

## One-liner

Adds the AnchorsSection.tsx sidebar primitive and wires it into the right-sidebar BCs tab above the existing External Inputs body, gated by FlowPort presence — closing the per-component pressure-anchor UI loop that Plan 03's anchors slice opened.

## Behaviour Delivered

Selecting a component in the canvas now drives the right-sidebar BCs tab as follows (D-04 / D-09 / D-10):

| Component class | BCs tab visible? | BCs body content |
| --- | --- | --- |
| Pump, Resistor, Gravity, Inertia, etc. (FlowPort, no external_inputs) | Yes (new — was: no) | Anchors section only |
| Channel, ChannelHeatFlux, ChannelAndContacts (FlowPort + external_inputs) | Yes | Anchors section, Separator, External Inputs section |
| WallTemperature, HeatFluxSource (BCPort only, no FlowPort, no external_inputs) | No | — |

Within the Anchors section:

- **State A (empty)**: muted "No anchor set" line + outline `+ Add anchor` button. Click → `setAnchor(nodeId, {portField:"port_in.P", value:0})`.
- **State B (populated)**: `Port` label + Select (`port_in.P` | `port_out.P`) + `Pressure` NumericField (`Pa`) + ghost `Clear anchor` button.

The BCs tab itself stays in the right sidebar — no relocation (D-10).
