## Sampling Rate

- **After every task commit:** Run the targeted vitest pattern for the touched files (`cd gui && pnpm test --run <file-or-pattern>`).
- **After every plan wave:** Run the full GUI suite (`cd gui && pnpm test --run`).
- **Before `/gsd-verify-work`:** Full GUI suite must be green; manual smoke checklist (Manual-Only Verifications table below) must be exercised.
- **Max feedback latency:** ~30s for the full suite; ~3s for pattern-scoped runs.
