| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap in toolbox items, handle offsets |
| sm | 8px | Compact element spacing (toolbox item vertical gap, node inner padding) |
| md | 16px | Default element spacing (panel padding, section gaps) |
| lg | 24px | Section padding (toolbox category heading margin-top) |
| xl | 32px | Welcome overlay internal padding |

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.33 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Node type label | 11px | 400 (regular) | 1.2 |

Notes:
- Body (14px): sidebar parameter labels, toolbox item labels, code preview text
- Label (12px): category headings in toolbox ("HYDRAULIC", "THERMAL"), node component type label (currently `text-xs text-muted-foreground`)
- Heading (18px): panel titles ("Components"), welcome overlay title
- Node type label (11px): component type on canvas node first line (small, accented)
- Two weights only: 400 (regular) and 600 (semibold). No bold (700) or light (300).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` oklch(1 0 0) = white | Canvas background, panel backgrounds |
| Secondary (30%) | `var(--card)` oklch(1 0 0) / `var(--muted)` oklch(0.97 0 0) | Node cards, sidebar surface, toolbox surface, toolbar bar |
| Accent (10%) | See category accents below | Node left-border stripe, toolbox category indicator |
| Destructive | `var(--destructive)` oklch(0.577 0.245 27.325) = red | Delete node confirmation, validation errors |

### Category Accent Colors

These are the two semantic accents for component type differentiation (per D-03):

| Category | Tailwind Class | CSS Value | Used On |
|----------|---------------|-----------|---------|
| Hydraulic | `border-l-blue-500` | #3b82f6 | Node left-border stripe, toolbox category dot/indicator |
| Thermal | `border-l-amber-500` | #f59e0b | Node left-border stripe, toolbox category dot/indicator |

Accent reserved for:
1. Canvas node left-border stripe (3px, category color)
2. Toolbox category heading color indicator
3. Selected node ring uses `var(--ring)` (existing, not category color)
4. Interactive hover states use `var(--accent)` (existing shadcn token, neutral)

The category colors (blue-500, amber-500) are NOT used for buttons, links, or general interactive elements. They are strictly for component type identification.

## Panel Layout

### Three-Panel Structure (DSGN-02)

```
+--------+------------------------+--------+
| Toolbox|       Canvas           |Sidebar |
| (left) |  + Toolbar (top)       |(right) |
|        |  + BottomPanel (bottom)|        |
+--------+------------------------+--------+
```

### Panel Dimensions

| Panel | Min Width | Default Width | Max Width |
|-------|-----------|---------------|-----------|
| Toolbox (left) | 120px | 240px (w-60) | 360px |
| Sidebar (right) | 200px | 320px | 400px |
| Canvas (center) | fills remaining space | flex-1 | unbounded |

### Collapse Behavior (D-06, D-07)

Each panel (toolbox, sidebar) has two affordances:

1. **Chevron toggle button**: Positioned at the inner edge of each panel, vertically centered. Uses shadcn `Button` variant="ghost" size="icon" (32x32px). Icon: `ChevronLeft`/`ChevronRight` depending on panel side and collapsed state.
   - Toolbox collapsed: chevron points right (expand). Expanded: chevron points left (collapse).
   - Sidebar collapsed: chevron points left (expand). Expanded: chevron points right (collapse).
   - When collapsed: the chevron button remains visible at the edge as a 32px-wide strip.

2. **Drag handle**: 6px-wide vertical strip on the inner edge of each panel. Cursor: `col-resize`. On mousedown + mousemove, resizes the panel between min and max width. The drag handle overlaps with or is adjacent to the chevron button area.

### Zustand Store Additions (D-07)

```typescript
toolboxCollapsed: boolean    // default: false
sidebarCollapsed: boolean    // default: false
setToolboxCollapsed: (collapsed: boolean) => void
setSidebarCollapsed: (collapsed: boolean) => void
// Panel widths are local component state (CSS), not persisted
```

No disk persistence for panel state. Resets on app restart.
