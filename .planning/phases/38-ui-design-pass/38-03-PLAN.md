  <action>
    Present the following verification checklist to the user. Run `cd gui && npm run tauri dev` (or `npm run dev` for browser-only) to launch the app.

    **What was built:** Complete UI design pass — component icons on canvas nodes and toolbox items, category color differentiation (blue Hydraulic / amber Thermal left-border stripes), collapsible and resizable toolbox and sidebar panels, shadcn/ui audit.

    **Verification steps:**

    1. **Toolbox icons (DSGN-03):**
       - Left toolbox shows Hydraulic and Thermal category sections
       - Each component has a distinct Lucide icon to the left of its label
       - Verify at least 3 icons look reasonable (e.g., Pump = gauge, Gravity = arrow down, HeatDiffusion = grid)

    2. **Canvas node design (DSGN-04):**
       - Drag a Pump onto the canvas — node should have a blue left-border stripe and a Gauge icon next to "Pump" type label
       - Drag a ConstantTemperature onto the canvas — node should have an amber left-border stripe and a ThermometerSun icon
       - Instance name should appear bold below the type label
       - Click a node — selection ring should appear around the card without conflicting with the left border

    3. **Toolbox collapse/resize (DSGN-02):**
       - Find the chevron button on the right edge of the toolbox panel
       - Click it — toolbox should disappear, canvas should expand to fill the space, only the chevron strip remains
       - Click the chevron again — toolbox should reappear at its previous width
       - Drag the right edge of the toolbox — panel should smoothly resize between ~120px and ~360px

    4. **Sidebar collapse/resize (DSGN-02):**
       - Find the chevron button on the left edge of the sidebar panel
       - Click to collapse — sidebar disappears, canvas expands
       - Click to expand — sidebar reappears
       - Drag the left edge of the sidebar — resizes between ~200px and ~400px
       - Select a node — sidebar shows properties (existing functionality preserved)

    5. **shadcn/ui compliance (DSGN-01):**
       - No raw unstyled buttons or inputs visible anywhere
       - Collapse chevron buttons use shadcn ghost button style (subtle hover effect)
       - Tooltips appear on hover over collapse buttons

    6. **No regressions:**
       - Connect two components with an edge — edge draws correctly
       - Click a node — sidebar shows parameters
       - Undo/redo (Ctrl+Z, Ctrl+Shift+Z) works for canvas operations but does NOT toggle panel collapse state
       - Code preview (bottom panel) still works
       - Save/Load still works

    **Resume signal:** Type "approved" or describe issues to fix.
