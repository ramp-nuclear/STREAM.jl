<objective>
Replace the sentinel-kwargs PipeGeometry constructor with a redesigned struct that stores wet_perimeter and derives Dh = 4*area/wet_perimeter, and add PipeGeometry_rectangular / PipeGeometry_circular factory functions matching Python EffectivePipe semantics.

Purpose: The old struct accepted a caller-provided Dh=0.01 for MTR channels, which is a 10 mm circular approximation instead of the correct ~2.5 mm rectangular value. This Dh error propagates into Re, Nu, h_tc, and all VAL reference constants. This plan is the physics correction.

Output: Redesigned PipeGeometry struct in src/components.jl; all ~20 call sites migrated in test/runtests.jl; new PHY-01 unit testsets verifying geometry fields; VAL-01/02/03 tests will knowingly fail after this plan (Dh shifts, reference constants not yet updated — fixed in Plan 02).
</objective>

    4. Add these two factory functions immediately after the struct definition:

       PipeGeometry_rectangular(L, edge1, edge2, heated_edge; one_sided=nothing):
       - area = Float64(edge1) * Float64(edge2)
       - wet_perimeter = 2.0 * (Float64(edge1) + Float64(edge2))
       - Dh = 4.0 * area / wet_perimeter
       - if one_sided === nothing: heated_perimeter = 2.0*Float64(heated_edge), heated_parts = (Float64(heated_edge), Float64(heated_edge))
       - if one_sided === :left:   heated_perimeter = Float64(heated_edge), heated_parts = (Float64(heated_edge), 0.0)
       - if one_sided === :right:  heated_perimeter = Float64(heated_edge), heated_parts = (0.0, Float64(heated_edge))
       - else: error("one_sided must be :left, :right, or nothing; got $one_sided")
       - return PipeGeometry(Float64(L), Dh, area, heated_perimeter, wet_perimeter, heated_parts)

       PipeGeometry_circular(L, D):
       - _D = Float64(D)
       - area = π * _D^2 / 4
       - perimeter = π * _D
       - heated_parts = (perimeter/2, perimeter/2)   # keep Julia convention (symmetric split); NOT Python's (perimeter, 0.0)
       - return PipeGeometry(Float64(L), _D, area, perimeter, perimeter, heated_parts)
       # Note: Dh = D for circular since 4*(π*D²/4)/(π*D) = D
