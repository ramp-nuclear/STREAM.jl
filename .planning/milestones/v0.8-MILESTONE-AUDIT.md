## Cross-Phase Integration Findings

### Notes

#### PERS-01 Save Behavior (Intentional Design)

`saveProject()` and `saveProjectAs()` call `validateAndGate()` and block on invalid topology — this is the intended behavior. Only validated canvases can be saved. Confirmed as correct by project owner.

---

#### HydraulicEdge Simplification (Committed, Intentional)

Phase 44 simplified `HydraulicEdge.tsx` to plain `getSmoothStepPath`. The previous parallel arc routing (MARGIN + `parallelOffset` cubic bezier) was removed. Arrowheads distinguish direction on bidirectional edge pairs. Committed in `1d2dbcf`. Intentional simplification.

---

### Moderate Issues

#### Issue 1 — PERS-04 FileMenu Gap

`recentFiles` only surfaced in `WelcomeOverlay`. Once any node exists, WelcomeOverlay disappears. `FileMenu.tsx` (84 lines) has no Open Recent submenu. User cannot navigate to a different recent project without Ctrl+O → full file browser.

**PERS-04 verdict:** Technically satisfied (requirement specifies "startup/empty canvas screen"). Flagged as tech debt for FileMenu enhancement.
