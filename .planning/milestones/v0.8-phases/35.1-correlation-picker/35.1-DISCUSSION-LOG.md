## Decisions Made

### Description Surfacing
- **Chosen:** Info icon (ⓘ) next to field label, shadcn Tooltip on hover
- **Rejected:** Secondary text below label (too much vertical noise in 320px sidebar)
- **Rejected:** Tooltip-on-label-hover (zero discoverability)
- **Scope:** Retrofit ALL existing field components (NumericField, FunctionSelect, PipeGeometryPicker, InstanceNameField) — not just new Phase 35.1 fields

### Sub-field Layout
- **Chosen:** Indented inline — sub-fields appear directly below parent dropdown, left border accent, no expand/collapse
- **Rejected:** Flat (no indentation — hierarchy unclear)

### Store Value Shape
- **Chosen:** Heterogeneous — simple closures stay as plain strings; factory selections become `{ kind: "factory", value: string, subParams: Record<string, unknown> }`
- **Rejected:** Flatten factory params (mixes correlation name with sub-params at same level)
- **Rejected:** Always use object (breaks Phase 35 store entries)
