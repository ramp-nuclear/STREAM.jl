## What Was Built

`FunctionSelect` now:
1. **No disabled factory entries** — all `SelectItem` entries are enabled.
2. **Correct value extraction** — `extractSelectValue` handles `string`, `FactoryCorrelationValue`, and fallback to default; fixes the `String(value)` → `"[object Object]"` bug from before.
3. **Factory selection** emits `{ kind: "factory", value: name, subParams: {} }` (fresh subParams on option switch per D-05).
4. **Simple closure selection** emits a plain `string` (D-06).
5. **Sub-field container** rendered below the select when `isFactory && subParams.length > 0`, using `border-l-2 border-muted pl-3 mt-1` indentation.
6. **Sub-fields**: `NumericField` for `Real`/`Int` sub-params, recursive `FunctionSelect` for `Function` sub-params (D-11: sub-function options are always `kind: "simple"`).
7. **Sub-param merging** via `handleSubParamChange` spreads existing `currentSubParams` and overrides one key at a time.

`ParameterForm.tsx` required no code changes — the `onChange` callback passes `v` as `unknown` to `onParamChange`, which already accepts `unknown`.
