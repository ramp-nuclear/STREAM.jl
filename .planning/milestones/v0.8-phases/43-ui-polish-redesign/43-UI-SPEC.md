## Bottom Panel Resize Contract

Source: CONTEXT.md D-01, D-02, D-03

### Interaction

| Property | Value |
|----------|-------|
| Drag handle location | Top border of BottomPanel |
| Drag handle height | 8px (hit area); 2px visible border highlight on hover |
| Cursor | `row-resize` |
| Clamping | Client-side during drag (not on mouse-up) |
| Min height | 120px |
| Max height | 60% of viewport height |
| Default height | 240px |

### Store Shape

```typescript
bottomPanelHeight: number        // default: 240
setBottomPanelHeight: (h: number) => void
```

Height persists within session (survives panel close/reopen). Resets on app restart. No disk persistence.

### Visual Behavior

- Idle: top border of BottomPanel shows standard `border-t` (1px `var(--border)`)
- Hover: 2px highlight in `var(--ring)` color, cursor changes to `row-resize`
- Dragging: same 2px highlight, panel resizes in real-time following cursor

## Parameter Field Description Tooltips

Source: CONTEXT.md D-04, D-05, D-06

### Reference Implementation

`NumericField.tsx` already implements the Info icon + tooltip pattern. The exact pattern to replicate:

```
<Label className="text-[13px] font-semibold leading-[1.4] flex items-center gap-1">
  {param.name}
  {param.description && (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger asChild>
          <Info className="h-3 w-3 text-muted-foreground cursor-default" />
        </TooltipTrigger>
        <TooltipContent>{param.description}</TooltipContent>
      </Tooltip>
    </TooltipProvider>
  )}
</Label>
```

### Components Needing Tooltip Addition

| Component | Current State | Action |
|-----------|---------------|--------|
| NumericField.tsx | Has tooltip | No change (reference) |
| PipeGeometryPicker.tsx | No tooltip | Add Info icon + tooltip to label |
| FunctionSelect.tsx | No tooltip | Add Info icon + tooltip to label |
| MatrixBadge.tsx | No tooltip | Add Info icon + tooltip to label |
| ParameterForm.tsx (bool toggle) | No tooltip | Add Info icon + tooltip to inline label |

### Tooltip Specs

| Property | Value |
|----------|-------|
| Icon | `Info` from lucide-react |
| Icon size | 12px (h-3 w-3) |
| Icon color | `text-muted-foreground` |
| Icon cursor | `cursor-default` |
| Tooltip primitive | shadcn `TooltipProvider` > `Tooltip` > `TooltipTrigger` + `TooltipContent` |
| Tooltip content | `param.description` string from registry (already populated) |
| Show condition | Only when `param.description` is truthy |

## Thermal Handle Proportions

Source: CONTEXT.md D-07, D-08

### Current State

- ChannelAndContacts renders exactly 2 thermal handles (one `thermal_left` on top, one `thermal_right` on bottom)
- Diamond shape: `borderRadius: 0`, `transform: rotate(45deg)`
- Current size: 10x10px
- Color: #f59e0b fill, 1px solid #d97706 border

### Adjusted Proportions (Claude's Discretion)

| Property | Current | New |
|----------|---------|-----|
| Width | 10px | 12px |
| Height | 10px | 12px |
| Border width | 1px | 1.5px |
| Border radius | 0 | 0 (diamond via rotate) |
| Transform | rotate(45deg) | rotate(45deg) |

Rationale: 12px diamond sits more proportionally next to the default ReactFlow circle handles (which render at ~10px diameter). The 1.5px border matches FlowPort handle border weight for visual consistency.
