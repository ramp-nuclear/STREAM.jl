<decisions_made>

- `pathOptions.offset` in ReactFlow SmoothStep controls step distance from node boundary, NOT
  lateral path separation. This is a ReactFlow API gotcha — do not use it for parallel edges.
- Bidirectional detection uses node IDs only (not handle names) — real loops use different port
  names each direction (port_out → port_in), handle-matching would fail.
- "Racetrack over/under" routing chosen over quadratic bezier arc (ReactFlow BiDirectionalEdge
  approach) because: both STREAM edges always go right→left, so arc direction detection via
  `sourceX < targetX` gives same direction for both edges; racetrack avoids crossing entirely.
- MARGIN = 60px: ~40px to clear nodeHeight/2, ~20px visual gap. Adjust if nodes look too tight.
- port_in = blue-400 (#60a5fa), port_out = red-400 (#f87171). User found blue-300/blue-700
  too similar. Red for "outgoing" (fluid leaving component), blue for "incoming".

</decisions_made>

The research done: ReactFlow's official BiDirectionalEdge uses `Q centerX centerY+offset` (quadratic

edges go right→left. Cytoscape.js, yEd, draw.io all route bidirectional pairs to opposite sides.
