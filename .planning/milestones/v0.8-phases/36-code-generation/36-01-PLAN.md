    Create `gui/src/lib/codeGenerator.ts` as a pure function module with zero React dependencies.

    **Exported interface:**
    ```typescript
    export interface BCEntry {
      nodeId: string;
      portField: "port_in.P" | "port_out.P";
      value: number;
    }

    export function generateCode(
      nodes: Node[],
      edges: Edge[],
      bcs: BCEntry[],
      getComponent: (id: string) => ComponentDefinition | undefined
    ): string;
    ```

    **Implementation details per D-06 through D-10:**

    1. **Header** (always emitted, even with no nodes -- but if nodes.length === 0, return just the empty-state comment):
       ```
       using ModelingToolkit, STREAM
       using ModelingToolkit: t_nounits as t
       ```

    2. **Components section** -- iterate `nodes` in array order (insertion order per D-10). For each node:
       - Look up `ComponentDefinition` via `getComponent(node.data.componentId)`
       - Look up active `ConstructorMode` via `component.constructorModes.find(m => m.mode === node.data.constructorMode)` (fallback to `constructorModes[0]`)
       - Get active parameter names from `mode.parameters`
       - For each active param name, find `Parameter` definition from `component.parameters`
       - **Default elision per Research Pitfall 5**: Compare `node.data.parameters[param.name]` against `param.default`. If equal, skip it. Exception: required params with no default must always be emitted.
       - Partition remaining params into positional (`param.positional === true`) and keyword (`param.positional === false`)
       - **Emit positional first** (in order), then `; ` separator if any kwargs follow, then kwargs as `name=value`
       - Format values using `formatParamValue(param, value)`:
         - `Real`: ensure decimal point (append `.0` to integers). `String(n)` then check for `.` or `e`/`E`; if absent, append `.0`
         - `Int`: `String(Math.round(n))` -- no decimal
         - `Bool`: `true` / `false`
         - `PipeGeometry`: `{ type: "circular", L, D }` -> `PipeGeometry_circular(L_formatted, D_formatted)`. `{ type: "rectangular", L, W, H }` -> `PipeGeometry_rectangular(L_formatted, W_formatted, H_formatted)`. If any dimension is missing/empty, emit `# TODO: set geometry dimensions` instead.
         - `Function` (simple string): emit as bare identifier, e.g., `"dittus_boelter"` -> `dittus_boelter`
         - `Function` (factory object `{ kind: "factory", value, subParams }`): emit as `value(key1=formatted1, key2=formatted2, ...)`. For sub-params: use the same type-based formatting. Sub-params that are themselves Function-type follow the same simple/factory logic (one level of recursion). **Omit sub-params whose value matches their default** (look up sub_parameter definitions from the parent FunctionOption in the registry to get defaults).
       - Wrap with `@named instanceName = ComponentId(args)`
       - If `validateJuliaIdentifier(instanceName)` fails, prepend `# WARNING: Invalid identifier "instanceName" -- rename before exporting` on the line above (per D-09 from UI-SPEC)

    3. **Connections section** -- emit `eqs = [`:
       - For each edge: `    connect(sourceInstanceName.sourceHandle, targetInstanceName.targetHandle),`
         - Look up source node by `edge.source`, get its `instanceName`
         - Look up target node by `edge.target`, get its `instanceName`
         - `edge.sourceHandle` and `edge.targetHandle` are port names (e.g., `port_out`, `port_in`)
       - For each BC: `    instanceName.portField ~ value,`
         - Resolve `bc.nodeId` to a node; get its `instanceName`
         - If nodeId not found (deleted node), skip this BC silently
         - Format value as Real (ensure decimal point)
       - Close with `]`

    4. **System section** (per D-07):
       ```
       @named sys = ODESystem(eqs, t; systems=[pump_1, ch_1, ...])
       ssys = mtkcompile(sys)
       ```
       Systems list = node instanceNames in insertion order, comma-separated.

    5. **Solve stub**:
       ```
       # Solve (uncomment to run)
       # sol = solve(SteadyStateProblem(ssys, []), DynamicSS(Rodas5P()))
       ```

    - `formatReal(n: number): string`
    - `formatParamValue(param: Parameter, value: unknown): string`
    - `formatFunctionParam(value: unknown, options?: FunctionOption[]): string` -- handles both simple and factory; uses options array to look up sub_parameter defaults for omission
    - `formatPipeGeometry(value: unknown): string`
    - `emitComponentDeclaration(nodeData: StreamNodeData, component: ComponentDefinition): string`
