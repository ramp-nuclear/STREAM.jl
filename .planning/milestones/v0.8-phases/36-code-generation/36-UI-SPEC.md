# Phase 36 — UI Design Contract

> Visual and interaction contract for the Code Generation phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (New York style, Zinc base) |
| Preset | new-york/zinc with CSS variables (Tailwind v4) |
| Component library | Radix UI (via shadcn) |
| Icon library | Lucide React |
| Font | System stack: -apple-system, BlinkMacSystemFont, "Segoe UI", Inter, sans-serif |

**Pre-existing shadcn components (installed in Phase 33-35):** Button, Input, Select, Label, Tooltip, Badge, Separator, ScrollArea.

**New shadcn components needed for Phase 36:** Tabs (for Code/BCs tab switcher in bottom panel). No others required.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding within toolbar buttons |
| sm | 8px | Toolbar button spacing, BC row internal gaps |
| md | 16px | Bottom panel internal padding, tab content padding |
| lg | 24px | Not used in Phase 36 |
| xl | 32px | Not used in Phase 36 |
| 2xl | 48px | Not used in Phase 36 |
| 3xl | 64px | Not used in Phase 36 |

Exceptions: Bottom panel toolbar height is 36px (not a spacing token; this is a component dimension matching shadcn Button size="sm" at h-9).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 500 (medium) | 1.4 |
| Code | 13px | 400 (regular, monospace) | 1.6 |
| Tab label | 13px | 500 (medium) | 1.0 |

**Code font family:** `"JetBrains Mono", "Fira Code", "Cascadia Code", ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`. Use the first available system monospace. Do NOT import a web font -- rely on the fallback chain.

**Rationale:** 13px code at 1.6 line-height provides comfortable reading density for Julia code in a constrained bottom panel. 14px body matches the existing sidebar typography.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` / oklch(1 0 0) | Canvas area, app background |
| Secondary (30%) | `var(--muted)` / oklch(0.97 0 0) | Bottom panel background, toolbar background, BC row background |
| Accent (10%) | `var(--primary)` / oklch(0.205 0 0) | Export button fill, active tab underline, Code toggle when panel is open |
| Destructive | `var(--destructive)` / oklch(0.577 0.245 27.325) | BC delete button icon, validation error text |

Accent reserved for:
- Export button (primary CTA -- filled variant)
- Active tab indicator in bottom panel tab bar
- Code toggle button when bottom panel is expanded (outline variant with accent border)

**Code preview syntax colors (no highlighting library):** All code renders as plain monospace text in `var(--foreground)` on `var(--muted)` background. No syntax highlighting in Phase 36. This is a deliberate simplification -- Phase 38 (UI Design Pass) may add highlighting if warranted.

## Interaction Contracts

### Code Toggle Button

| Property | Value |
|----------|-------|
| Label | "Code" |
| Icon | `Code2` from Lucide (left of label) |
| Variant (panel closed) | `ghost` size `sm` |
| Variant (panel open) | `outline` size `sm` with `border-primary` |
| Click behavior | Toggles bottom panel visibility |
| Keyboard | No dedicated shortcut in Phase 36 |

### Export Button

| Property | Value |
|----------|-------|
| Label | "Export" |
| Icon | `Download` from Lucide (left of label) |
| Variant | `default` size `sm` (filled accent/primary) |
| Click behavior | Opens Tauri native save dialog, default filename `system.jl`, filter `.jl` |
| Disabled state | Visually disabled when canvas has zero nodes (nothing to export) |

### BC Panel (BCs Tab)

**Add row form layout (single horizontal row):**
```
[Component v] . [Port.Field v] ~ [Value ____] [+ Add]
```

| Element | Component | Width | Details |
|---------|-----------|-------|---------|
| Component dropdown | shadcn Select | 140px | Populated from canvas node instanceNames. Placeholder: "Component" |
| Dot separator | Static text "." | auto | `text-muted-foreground` |
| Port.Field dropdown | shadcn Select | 120px | Options: `port_in.P`, `port_out.P` only. Placeholder: "Port" |
| Tilde separator | Static text "~" | auto | `text-muted-foreground`, `font-mono` |
| Value input | shadcn Input | 120px | Numeric. Placeholder: "1.0e5" |
| Add button | shadcn Button | auto | Label: "Add", variant: `outline`, size: `sm`. Disabled when any field is empty. |

**BC entry row (existing entries):**
```
pump_1.port_in.P ~ 1.0e5                                    [x]
```

| Element | Details |
|---------|---------|
| Expression text | `font-mono text-sm` showing `{instanceName}.{portField} ~ {value}` |
| Delete button | shadcn Button `variant="ghost" size="icon"` with Lucide `X` icon, 16px. On hover: `text-destructive`. |
| Row background | `var(--muted)` with `rounded-md` and `px-3 py-1.5` |
| Row spacing | 8px gap between rows |

**Empty state (no BCs added):**
```
No boundary conditions added.
Add a pressure anchor (e.g., pump.port_in.P ~ 1.0e5).
```

### Code Preview (Code Tab)

| Property | Value |
|----------|-------|
| Font | Monospace chain (see Typography section) |
| Font size | 13px |
| Background | `var(--muted)` |
| Text color | `var(--foreground)` |
| Padding | 16px |
| Scroll | Vertical via shadcn ScrollArea. Horizontal overflow: `overflow-x-auto` with no wrapping (`white-space: pre`). |
| Selection | User can select and copy text (not `user-select: none`) |
| Line numbers | No line numbers in Phase 36. |
| Update trigger | Regenerated on every store change (nodes, edges, parameters, BCs). Memoized with `useMemo`. |

**Empty state (no nodes on canvas):**
```
# Add components to the canvas to generate Julia code.
```
Displayed as a single Julia comment line in the same monospace font and muted foreground color.

### Identifier Validation (CODE-07)

| Trigger | When component instanceName changes (already in Phase 35) AND at code generation time |
|---------|------|
| Invalid identifier display | Inline error below the instanceName field in the sidebar (existing Phase 35 pattern). Code preview shows `# WARNING: Invalid identifier "{name}" -- rename before exporting` as a Julia comment above the offending `@named` line. |
| Export blocked | Export button remains enabled but the generated file includes the warning comment. No modal/toast for invalid identifiers. |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Export" (Export button in toolbar) |
| Code toggle | "Code" (toolbar toggle button) |
| Tab labels | "Code" / "BCs" |

| BC component placeholder | "Component" |
| BC port placeholder | "Port" |
| BC value placeholder | "1.0e5" |
| Invalid identifier warning | `# WARNING: Invalid identifier "{name}" -- rename before exporting` |
| Export dialog default filename | `system.jl` |
| Export dialog filter label | "Julia files" |

**Destructive actions in this phase:** Deleting a BC entry. No confirmation dialog needed -- the action is lightweight (single row removal) and immediately reversible by re-adding.
