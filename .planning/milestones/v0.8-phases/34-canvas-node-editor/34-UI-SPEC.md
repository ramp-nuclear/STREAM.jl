| sm | 8px | Toolbox item internal padding, node card inner padding |
| md | 16px | Toolbox section padding, default element gaps |

| Secondary (30%) | `var(--card)` oklch(1 0 0) / `var(--border)` oklch(0.922 0 0) | Node card background (white with border), toolbox panel (w-60 border-r), sidebar panel |

### Phase 34 Specific Colors

| Element | Color | Rationale |
|---------|-------|-----------|
| FlowPort-out handle (source) | `var(--primary)` oklch(0.205 0 0) — dark dot | Matches primary foreground; visually distinct as connection source |
| FlowPort-in handle (target) | `var(--primary)` oklch(0.205 0 0) — dark dot | Same as source; directionality communicated by position (left=in, right=out), not color |
| Edge (connection line) | `var(--muted-foreground)` oklch(0.556 0 0) — medium gray | Neutral, does not compete with nodes |
| Selected node border | `var(--ring)` oklch(0.708 0 0) — ring color | Standard shadcn focus ring convention |
| Node card border (default) | `var(--border)` oklch(0.922 0 0) — light gray | Subtle, per shadcn card convention |
| Toolbox drag ghost | Browser default drag image | No custom drag preview in Phase 34 |

## Interaction Contracts

### Drag from Toolbox (CANV-02)

| Step | Actor | Behavior |
|------|-------|----------|
| 1 | User drags toolbox item | `onDragStart` sets `dataTransfer.setData("application/streamcomponent", componentId)` and `effectAllowed = "move"` |
| 2 | User drags over canvas | `onDragOver` calls `event.preventDefault()` and sets `dropEffect = "move"` |
| 3 | User drops on canvas | `onDrop` reads component id from `dataTransfer`, converts screen position via `screenToFlowPosition`, calls `addNode(componentId, position)` |
| 4 | Node appears | New node rendered at drop position with default name `{type}_{N}` (per-type counter, e.g. pump_1, pump_2) |

### Edge Drawing (CANV-03)

| Step | Actor | Behavior |
|------|-------|----------|
| 1 | User drags from FlowPort-out handle | ReactFlow initiates edge drawing from `source` handle |
| 2 | User hovers over FlowPort-in handle | `isValidConnection` returns `true` only if source handle type is `source` and target handle type is `target` (both FlowPort); returns `false` for same-direction connections |
| 3 | User releases on valid target | `onConnect` fires; store `addEdge` creates edge with `sourceHandle` and `targetHandle` IDs matching registry port names |
| 4 | Invalid target | Edge drawing cancels; no edge created |

### Node Selection and Deletion (CANV-04)

| Action | Trigger | Behavior |
|--------|---------|----------|
| Select node | Click on node | `selectNode(nodeId)` in store; node shows `var(--ring)` border; SidebarPanel reads `selectedNodeId` (Phase 35) |
| Deselect | Click on canvas background | `selectNode(null)` |
| Delete node | Select + Delete/Backspace key | Node removed; all connected edges removed; `selectNode(null)` |
| Delete edge | Select edge + Delete/Backspace key | Edge removed |
| Multi-select | Shift+click or ReactFlow box select | Multiple nodes/edges selected; Delete removes all |

### Undo/Redo (CANV-07)

| Action | Trigger | Behavior |
|--------|---------|----------|
| Undo | Ctrl+Z | zundo `undo()` restores previous store snapshot (nodes, edges, selectedNodeId) |
| Redo | Ctrl+Shift+Z / Ctrl+Y | zundo `redo()` restores next snapshot |
| Depth | N/A | At least 10 sequential operations (CANV-07 requirement) |
| Covered ops | N/A | add node, delete node, add edge, delete edge, move node |

### Node Rendering (CANV-06)

```
+---------------------------+
|  [o] port_in     port_out [o]  <- FlowPort handles (8px diameter circles)
|                               |
|  Channel                      |  <- type label: text-xs text-muted-foreground
|  channel_1                    |  <- instance name: font-semibold text-sm
+---------------------------+
```

- Node minimum width: 140px
- Node padding: 8px
- Node border: 1px solid `var(--border)`, rounded with `var(--radius)` (0.625rem)
- Node background: `var(--card)` (white)
- Handle diameter: 8px
- Handle border: 1px solid `var(--border)`
- Handle background: `var(--primary)` (dark)
- Selected node: border changes to 2px solid `var(--ring)`
