  <how-to-verify>
    Start the app: `cd gui && npm run tauri dev`

    **Test 1 — VALD-01: Unconnected port warning**
    1. Drag a Channel onto the canvas (do NOT connect it)
    2. Click the Export button in the toolbar
    3. Verify: An AlertDialog appears titled "Validation Failed" with the description "Fix the following issues before exporting."
    4. Verify: The dialog lists `channel_1: port_in unconnected` and `channel_1: port_out unconnected`
    5. Click "Back to Canvas"
    6. Verify: The Channel node now has a red ring outline visible on the canvas

    **Test 2 — VALD-02: Missing pressure BC**
    1. Place a Pump and a Channel, connect them in a loop (Pump port_out to Channel port_in, Channel port_out to Pump port_in)
    2. Do NOT add any boundary conditions in the BC panel
    3. Click Export
    4. Verify: Dialog appears with "No pressure boundary condition" under System Errors

    **Test 3 — VALD-03: No driving element**
    1. New project (Ctrl+N). Place two Channels, connect them
    2. Click Export
    3. Verify: Dialog shows "No driving element (add a Pump or Gravity component)"

    **Test 4 — D-06: Reactive clearing**
    1. From Test 1 state (Channel with red ring), add a Pump
    2. Connect Pump port_out to Channel port_in
    3. Verify: If Channel port_in error clears, the ring should either disappear (if port_out also got connected) or persist (if port_out still unconnected)
    4. Connect Channel port_out to Pump port_in
    5. Verify: Red ring on Channel disappears completely

    **Test 5 — D-07: Dual ring coexistence**
    1. Trigger validation on a node with errors
    2. After dialog dismiss, click the errored node to select it
    3. Verify: Both the blue selection ring and red error ring are visible simultaneously

    **Test 6 — Save validation gate**
    1. Place a single unconnected Channel
    2. Press Ctrl+S
    3. Verify: Validation dialog appears (save is blocked)

    **Test 7 — Valid topology passes through**
    1. Build a complete loop: Pump -> Channel -> Pump (connected)
    2. Add a pressure BC in the BC panel
    3. Click Export
    4. Verify: Native file save dialog appears (no validation dialog)
