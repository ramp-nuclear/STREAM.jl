  <action>
Present the running app to the user for manual verification of all PARA requirements.

Start the app: `cd gui && npm run dev` (or `npm run tauri dev`)

Verification steps for the user:

1. **PARA-01 - Selection:**
   - Drag a Channel from toolbox to canvas. Click it. Verify sidebar shows "Properties" heading, instance name field, "Channel" badge, and parameter fields (n, g, htc_correlation, friction_correlation, geometry section).
   - Click canvas background. Verify sidebar shows "No selection" / "Select a component on the canvas to view its properties."

2. **PARA-02 - Scalar editing:**
   - Click the Channel node. Change the "g" field from 0 to 9.80665 and tab away. Verify the value persists (click another node and back).

3. **PARA-03 - Pump mode toggle:**
   - Drag a Pump to canvas. Click it. Verify "Mode" section shows "Fixed dP" and "Fixed mdot" toggle. Default is Fixed dP showing dP_pump field.
   - Click "Fixed mdot". Verify dP_pump disappears and mdot0 field appears.
   - Toggle back. Verify dP_pump reappears.

4. **PARA-04 - PipeGeometry:**
   - Click the Channel node. Verify "Geometry" section shows segmented control [Circular | Rectangular].
   - Enter L=0.5, D=0.01 in circular mode.
   - Switch to Rectangular. Verify L and D fields are cleared (per D-02). Enter L=0.5, W=0.06, H=0.001.
   - Switch back to Circular. Verify W and H are gone, L and D are empty.

5. **PARA-05 - Rename:**
   - Click the Channel. Change instance name to "main_channel" and tab away. Verify canvas node label updates to "main_channel".
   - Try entering "123bad" and tab away. Verify error message appears.

6. **PARA-06 - Validation:**
   - In Channel's "n" field, type "abc" and tab away. Verify red error message appears below.
   - Type "-5" and tab away. Verify error.
   - Type "10" and tab away. Verify error clears.
   - In "g" field, type "Infinity" and tab away. Verify error about finite number.

7. **Function dropdown:**
   - In Channel, click htc_correlation dropdown. Verify "Dittus-Boelter" and "Constant Nusselt" are selectable. Verify "Regime Dependent", "Elenbaas", "Maximal HTC" are grayed out.
   - Hover a grayed-out item. Verify tooltip "Factory correlation editing coming in a future update".

8. **Node switching:**
   - With Channel selected, click Pump. Verify sidebar immediately shows Pump parameters (not Channel's).

Resume signal: Type "approved" if all checks pass, or describe any issues found.
