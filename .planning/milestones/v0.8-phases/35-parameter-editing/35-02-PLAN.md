**1. Create gui/src/components/sidebar/NumericField.tsx:**

A controlled input for Real and Int parameter types. Local state while typing, validate on blur per D-06. Unit suffix inside the input per UI-SPEC.

Props: `{ param: Parameter; value: unknown; onChange: (value: number) => void }` where `param` is from registry.

Implementation:
- `useState` for `localValue` (string) initialized from `String(value ?? param.default ?? "")`.
- `useState` for `error` (string | null) initialized to `null`.
- On change: `setLocalValue(e.target.value)` only. No validation.
- On blur: call `validateInt(localValue)` if `param.type === "Int"`, else `validateReal(localValue)`. If valid, `setError(null)` + `onChange(result.value)`. If invalid, `setError(result.message)` only -- do NOT call onChange (per D-06, invalid values not written to store).
- Use `key` prop pattern: parent will re-key on node switch to reset local state.
- Use shadcn `<Label>` for label (13px semibold per UI-SPEC). Show `param.name` and description as tooltip or secondary text.
- Use shadcn `<Input>` with `inputMode="numeric"` for Int, `inputMode="decimal"` for Real.
- Unit suffix: render `param.unit` inside a relative container to the right of the input (absolute positioned span with `text-muted-foreground text-[13px] font-semibold`). Add `pr-12` to input to prevent text overlap.
- Error: `{error && <p className="text-destructive text-xs">{error}</p>}` below the input.
- Error state: when error is set, add `border-destructive` class to Input.
- Spacing: gap-[8px] between label and input (sm), gap-[8px] between input and error.
