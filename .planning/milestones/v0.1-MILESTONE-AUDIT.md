## Tech Debt by Phase

### Phase 2: Components

1. **BUG-01 — H_grav MTK parameter unused in Gravity equation** (`src/components.jl:136`)
   - `port_in.P - port_out.P ~ rho_water(T_in) * 9.80665 * H` uses Julia kwarg `H` (Float64)
   - `H_grav` is declared as an MTK parameter but never appears in any equation
   - Contrast: `Channel` correctly uses `g_acc` (MTK symbolic) in its equation (line 71)
   - Fix: replace `H` with `H_grav` in the Gravity pressure equation

2. **Friction and Gravity components not wired into loop**
   - Both are tested in isolation but neither appears in `build_loop` or `build_loop_transient`
   - Friction: Channel handles friction internally via `dP` equation using Blasius
   - Gravity: Channel has `g_acc=0.0` default kwarg but `build_loop` never exposes this to the user
   - These are exported public API components with no current integration path

### Phase 3: Integration and Validation

3. **BUG-02 — Stale `ssys.fr.*` in solve_steady docstring** (`src/solvers.jl:115-116`)
   - Docstring says: `ssys.fr.port_in.mdot => mdot_guess` and `ssys.fr.Re => Re_guess`
   - Friction was removed from `build_loop` in commit `2e5ed5c`; `ssys.fr` does not exist
   - A user constructing `op` from the docstring example will get `KeyError` at runtime
   - Fix: update docstring to use `ssys.ch.port_in.mdot` and remove `ssys.fr.Re`

4. **Future refactor note deferred to v0.2** (`src/solvers.jl:2-6`)
   - Comments referencing future wrapper struct architecture

5. **Stale TDD test files not in Pkg.test() scope**
   - `test/test_transient_tdd.jl` — crashes if run (ssys.fr.* references, Q_wall_sym/T_wall_sym mismatch)
   - `test/test_solvers_tdd.jl` — not included by runtests.jl; dead scaffolding
   - Unstaged deletion of `test/test_comp_tdd.jl` in git working tree (needs `git rm` or restore)

6. **VAL-01/02/03 missing from 03-03-SUMMARY.md `requirements-completed` frontmatter**
   - Requirements are described in `provides` list but not in the structured field
   - Minor documentation inconsistency; no functional impact
