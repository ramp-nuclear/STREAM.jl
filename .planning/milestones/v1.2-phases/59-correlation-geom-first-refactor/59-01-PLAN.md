<interfaces>
PipeGeometry is a flat struct in src/geometry.jl. Fields read by friction
factories: `geom.depth` (Float64, shorter cross-section dimension) and
`geom.width` (Float64, longer cross-section dimension). Derived
`aspect_ratio = geom.depth / geom.width`.

For circular geometry constructed via PipeGeometry_circular(L, D): width == depth
== D, so aspect_ratio == 1.0 — `rectangular_laminar_correction(1.0)` ≈ 1.1246
giving f ≈ 56.9/Re (not the strict circular 64/Re). Acceptable per existing
laminar_friction docstring; circular-friction callers who want strict 64/Re
already use a raw lambda. Document this in the new docstring's note section
(no behavior change vs current laminar_friction(1.0) call site at examples.jl:441).
</interfaces>
</context>
