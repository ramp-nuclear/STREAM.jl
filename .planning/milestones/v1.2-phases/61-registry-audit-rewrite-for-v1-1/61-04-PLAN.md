<objective>
Re-audit the eight components that were unchanged by v1.1 structurally but may still have drifted from their source signatures: `Pump`, `Flapper`, `Friction`, `Gravity`, `Resistor`, `Inertia`, `HeatExchanger`, `ConstantTemperature`. For each, confirm that the registry's `parameters[]` list mirrors the current Julia constructor kwargs in the relevant `src/components/*.jl` file. Fix drift by editing in place — minimal change, no structural rewrites.

This plan also globally sunsets the legacy `array: true` / `arrayParam: <name>` port keys: if any port in `components.json` (outside of Plan 02's already-rewritten thermal pairs) still carries them, migrate to `array_size: <name>` and drop the legacy keys. The legacy keys will be removed from the TypeScript `Port` interface in a future cleanup phase (not Phase 61's scope).

Purpose: Without this audit, the registry mixes v0.7-era component bodies with v1.1-era ones, and `registry.test.ts` would lock in drift forever. This plan does the cleanup pass before Plan 05 updates the tests.

Output: Edits to the 8 unchanged-component entries in `components.json`. No new components added; no entries removed.
</objective>
