App.tsx listener-cleanup pattern (gui/src/App.tsx:332-365) — the project convention for Tauri event subscriptions:
- `useRef<(() => void) | null>(null)` to hold the unlisten function
- `let active = true` flag inside useEffect
- `.then((fn) => { if (!active) fn(); else unlistenRef.current = fn; })` to handle Strict Mode double-mount race
- Cleanup: `active = false; unlistenRef.current?.(); unlistenRef.current = null;`
