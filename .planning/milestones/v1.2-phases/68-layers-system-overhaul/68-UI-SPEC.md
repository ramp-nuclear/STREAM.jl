**Color square states on the chip:**

- Layer active (checkbox checked): square at full opacity (1.0) — solid color square
- Layer inactive (checkbox unchecked): square at opacity 0.35 — visibly muted but still identifiable as the color

**Rationale for 0.35 (not 0.4):** CONTEXT.md says "~0.4"; 0.35 gives better contrast discrimination in dark mode against the `bg-background` chip backdrop without washing out the hue.

**Both themes:** violet-500 (#8b5cf6) and rose-500 (#f43f5e) are sufficiently saturated to read in both light (white canvas) and dark (One Dark Pro #282c34 canvas) contexts. They sit far enough apart in hue (~300° vs ~350°) that they are distinguishable in all common color-deficiency types (deuteranopia: violet reads cool-purple vs rose reads warm-red).

**Off-layer edge dimming:** opacity 0.15 (existing value from `CanvasPanel.tsx` line 128; unchanged)

## Surface-Specific Contracts

### 1. Layers Chip (new component: `LayersChip.tsx`)

**Placement:** Appended to the bottom of the existing `absolute top-2 right-2 z-10 flex flex-col gap-1` overlay stack in `CanvasPanel.tsx`. Rendered as the last child below `SnapToGridButton`. Do NOT create a separate overlay cluster — consistency with Phase 65 pattern.

**Chip anatomy:**

```
[ ■ ■ ■ ■  Layers ]
```

- Outer container: same button class pattern as `SnapToGridButton` — `flex items-center justify-center rounded border shadow-sm transition-colors bg-background text-foreground border-border hover:bg-accent hover:text-accent-foreground`
- Width: auto (wider than 32px to accommodate 4 squares + label); minimum width ~80px; height 32px (h-8)
- Padding: px-2 (8px horizontal)
- Gap between squares: `gap-1` (4px)
- Gap between last square and "Layers" label: `gap-2` (8px)
- 4 color squares: 12px × 12px (w-3 h-3), `rounded-sm` (2px radius), inline-flex, NO border; opacity transitions at 150ms

**Active state when any layer is off:** chip background shifts to `bg-secondary` (slightly elevated) to signal "not showing everything" — same principle as `SnapToGridButton`'s active state using `bg-primary text-primary-foreground`; but Layers chip uses a softer indicator because "some off" is a common working state, not a binary lock.

**No text when all 4 layers are on:** chip is purely visual (4 full-opacity squares + "Layers" label at 12px weight-600 text-foreground)

**Popover trigger:** clicking anywhere on the chip opens the shadcn `<Popover>`. Close on outside-click (Radix default).

### 2. Layers Popover (inside `LayersChip.tsx`)

**Container:** `PopoverContent` with `side="left"` and `align="start"` — opens to the left of the chip so it doesn't overflow the right edge of the window. Width: `w-52` (208px). Padding: `p-3` (12px).

**Layout:**

```
┌─────────────────────────────────┐
│ Layers                          │
├─────────────────────────────────┤
│ ■ Hydraulic           [✓]       │
│ ■ Thermal             [✓]       │
│ ■ Sources             [✓]       │
│ ■ Reactor Physics     [✓]       │
├─────────────────────────────────┤
│ OFF-LAYER                       │
│ [Dim]   [Hide]                  │
└─────────────────────────────────┘
```

- Header "Layers": 12px, weight-600, `text-foreground`, `mb-2`
- Separator between header and checkbox list: none (header mb-2 creates sufficient visual rhythm)
- Each checkbox row: `flex items-center gap-2 py-1` (4px top+bottom, 8px gap)
  - Color square: 12px × 12px (w-3 h-3), `rounded-[2px]`, full opacity (it's a legend swatch, not a state indicator; actual state is shown by the Checkbox)
  - `<Checkbox>` (shadcn — must be installed): default size, checked=`activeLayers[key]`, `onCheckedChange={() => toggleLayer(key)}`
  - Label: 13px, weight-400, `text-foreground`, cursor-pointer
  - Row order: Hydraulic → Thermal → Sources → Reactor Physics (matches layer taxonomy table ordering)
- Separator: `<Separator className="my-2" />` between checkbox group and Off-layer toggle
- Off-layer section:
  - Section label: `text-[12px] font-semibold uppercase tracking-[0.08em] text-muted-foreground mb-2` — matches CodePreview section header style (8px bottom margin, on-grid)
  - Toggle row: two `<Toggle>` buttons side by side (already installed `gui/src/components/ui/toggle.tsx`); `variant="outline"` size="sm"
    - Left: "Dim" — pressed state = `hideOffLayer === false`
    - Right: "Hide" — pressed state = `hideOffLayer === true`
    - Both: `flex-1 text-[12px]`; no icons (labels are self-explanatory)

**Why Toggle pair instead of Switch:** Switch implies a two-value boolean ("off/on") which is ambiguous here — the user is choosing between two named modes. A paired toggle button group ("Dim" / "Hide") names both states explicitly. Switch is not installed; Toggle is. No new component install required.

### 3. Off-layer Visual State

**Dim mode (default, `hideOffLayer === false`):**

- Fully off-layer node (all its layers are unchecked): `opacity: 0.2`, `pointerEvents: "none"`, `transition: "opacity 150ms ease"`
  - ReactFlow node props: `selectable: false`, `draggable: false`
- Dual-layer node with one layer off (e.g., CAC with Thermal off but Hydraulic on): node visible at full opacity; off-layer port handles only dim to `opacity: 0.2` via inline style on the handle element + `pointerEvents: "none"`
- Off-layer edge: `opacity: 0.15`, `transition: "opacity 150ms ease"`; edge is non-interactive (ReactFlow handles this when both endpoints are locked, or via `interactionWidth: 0` on edge data)

**Hide mode (`hideOffLayer === true`):**

- Fully off-layer node: ReactFlow node prop `hidden: true` (ReactFlow v12 renders nothing for hidden nodes; they retain position in store)
- Dual-layer node with one layer off: node remains visible; off-layer port handles set `display: none` (not `hidden` — ReactFlow handles visibility per-node, not per-handle)
- Off-layer edge: `hidden: true` on edge object

**Transition:** opacity change animates at 150ms ease (consistent with existing CanvasPanel enrichment). Hidden mode does NOT animate (display:none is instantaneous — acceptable per engineering-tool aesthetic; no transition-on-hide complexity).

### 4. Bottom-Panel Header Redesign

**Closed state — stub strip:**

  - Label: `<span className="text-[12px] font-normal text-muted-foreground">Code</span>`
  - Icon: `<ChevronUp className="w-3 h-3 text-muted-foreground" />`
  - Full row is clickable (entire 20px strip is the click target, not just the icon/label)
- Height: exactly 20px (h-5)

**Exact stub label:** "Code" with `ChevronUp` icon to the right — matches VS Code's bottom-panel closed state pattern. The label is intentionally minimal; the chevron is the affordance indicator.

## Interaction Contract

### Layer toggle behavior

- Clicking a color square on the chip does NOT toggle the layer — the square is a status indicator, not a button. The entire chip is the popover trigger.
- Checking/unchecking a layer checkbox: immediate visual effect on canvas (150ms opacity transition in dim mode; instant in hide mode). No confirmation, no undo (layer state is not in undo history — it is layout/view state, not model state).
- Toggling Dim/Hide: immediate canvas re-render. Transition: none (switching between 0.2 opacity and display:none does not animate).

### Layer-aware connect

- User drags connection from a port on an active-layer node to a port on an off-layer node
- Connection is allowed (not blocked)
- Post-connect: if any newly connected layer was hidden (`activeLayers[key] === false`), call `setLayerVisible(key, true)` for each such layer
- Visual result: the previously hidden node and its connections immediately become visible (layer auto-enabled)
- No user notification — the visual change is self-evident

### Keyboard interactions

- Tab key: no longer cycles layers (D-06 removed)
- Clicking away from the Layers popover: closes the popover (Radix default outside-click dismiss)
- Ctrl+` (or existing keyboard shortcut in ViewMenu): toggles bottom panel open/closed — calls same `toggleBottomPanel()` action as the collapse button and the stub strip click

### Accessibility

- Layers chip: `aria-label="Open layer visibility controls"`, `aria-expanded={popoverOpen}`
- Each checkbox row: `<label>` wraps the `<Checkbox>` and the text label (shadcn Checkbox default pattern)
- Color squares on chip and in popover: `aria-hidden="true"` (decorative; the checkbox label conveys the layer name)
- Bottom-panel stub: `role="button"` implied by the `cursor-pointer` div; explicit `aria-label="Expand code panel"`
