    Create loopTraversal.ts exporting:
      - HydraulicLoop interface: { nodeIds: string[]; edgeIds: string[] } (per RESEARCH Pattern 6).
      - findHydraulicLoops(nodes: Node[], edges: Edge[], getComponentDef: (id: string) => ComponentDefinition | undefined): HydraulicLoop[]

    Algorithm: build an adjacency map keyed by nodeId, where each adjacency entry records (targetNodeId, edgeId, sourceHandle, targetHandle). Filter edges so that only edges whose sourceHandle resolves to a Port of type 'FlowPort' on the source node's component AND whose targetHandle resolves to a Port of type 'FlowPort' on the target node's component participate. Filter nodes to those that have at least one FlowPort in their component definition (Pitfall 6).

    Use Tarjan strongly-connected-components OR a simple DFS with a visiting/visited stack to discover cycles. Each SCC of size >= 2 is one HydraulicLoop. Single-node SCCs (no self-loop) are not loops. Return the ordered nodeIds for each loop in discovery order; tests assert on Set equality.

The function MUST be deterministic across runs (same input → same output) — sort nodeIds before iterating to avoid Map insertion-order surprises.
