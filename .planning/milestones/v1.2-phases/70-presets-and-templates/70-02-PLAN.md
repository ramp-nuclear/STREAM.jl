    5. `PresetIndexEntry` — `{ name: string; description: string; filePath: string; store: "project" | "library" }` (consumed by useStore.ts in plan 70-03; declare here to keep types co-located with the schema).
    6. `SerializePresetArgs` — args for `serializePreset`: `{ name: string; description: string; components: Node[]; connections: Edge[]; geometries: GeometryResource[]; powerShapes: PowerShapeResource[]; layout: Record<string, { x: number; y: number }> }`. Fluids array always empty (matches `serializeProject` light-water exclusion noted in RESEARCH.md Q5).
    7. `serializePreset(args: SerializePresetArgs): string` — builds the `StreamPreset` and returns `JSON.stringify(preset, null, 2)`. Before assembling, strip `data.autoExtended` from every component node (per Pitfall 7 — defense in depth, even though the caller in 70-03 also strips). Stripping = shallow clone of `data` without the `autoExtended` key.
    8. `deserializePreset(json: string): StreamPreset` — `JSON.parse`, then:
        - if `parsed.format_version !== PRESET_FORMAT_VERSION` → throw `Error("Invalid .scpr file: expected format_version '" + PRESET_FORMAT_VERSION + "', " + (parsed.format_version === undefined ? "missing format_version" : "got '" + String(parsed.format_version) + "'"))`.
        - if `parsed.kind !== "preset"` → throw `Error("Invalid .scpr file: expected kind 'preset', got '" + String(parsed.kind) + "'")`.
        - Then build and return a fully-typed `StreamPreset`, with defensive defaults only for optional-by-convention fields: `description ?? ""`, `resources.fluids ?? []`. No defaults for `format_version`, `kind`, `name`, `components`, `connections`, `layout` — those are required-by-schema, and missing fields surface as type errors in tests.
    9. `autoExtendSelection(selectedNodeIds: Set<string>, allNodes: Node[], allEdges: Edge[]): { extendedIds: Set<string>; keptEdges: Edge[]; droppedEdges: Edge[] }` — per RESEARCH.md Q4: copy `selectedNodeIds` into a new `extendedIds`. Single-pass iterate `allEdges`; for each edge with `edge.type === "bcEdge"`, if exactly one of `source`/`target` is in `extendedIds` (XOR check via `has(source) !== has(target)`), add the other endpoint to `extendedIds`. This is one hop only — no second pass. After extension, partition all edges: an edge is kept iff `extendedIds.has(e.source) && extendedIds.has(e.target)`; otherwise dropped. Return all three values.
    10. `normalizeLayout(nodes: Node[]): Record<string, { x: number; y: number }>` — compute `minX = Math.min(...nodes.map(n => n.position.x))` and `minY = Math.min(...nodes.map(n => n.position.y))` (or `0` if nodes is empty), then return a record keyed by node id mapping to `{ x: position.x - minX, y: position.y - minY }`.

## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-70-04 | Tampering | `deserializePreset` JSON parse | mitigate | Strict `format_version === "1.0"` and `kind === "preset"` literal checks; both throw on mismatch. No `eval`; no `new Function`. Per CLAUDE.md no-back-compat — old files break loudly. |
| T-70-05 | Denial of Service | `deserializePreset` parsing pathologically large JSON | accept | `.scpr` files are user-generated and stored locally. No remote source. Tauri-side `readTextFile` is the upstream gate; no size cap added at this layer. |
| T-70-06 | Information Disclosure | `serializePreset` stripping `data.autoExtended` | mitigate | Defense-in-depth stripping inside serializePreset prevents the transient highlight field from leaking into `.scpr` even if a caller forgets to strip (Pitfall 7). Test 1.2 locks the behavior. |
| T-70-07 | Tampering | Preset `name` charset (D-10) | mitigate | `PRESET_NAME_RE` `/^[A-Za-z0-9_-]+$/` rejects path separators, parens, `..`, spaces, Unicode. Consumer in 70-03 calls `isValidPresetName` before any `writeTextFile`. |
