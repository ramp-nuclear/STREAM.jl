## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tauri webview ↔ FS plugin | All `.scpr` reads, writes, removes, and renames cross into the Rust core; the ACL from plan 70-01 gates which paths are allowed. |
| Loaded `.scpr` JSON → store state | A `.scpr` file may be hand-edited; the parsing layer (presetIO from 70-02) does strict version+kind checks, but the slice further trusts the schema (component shapes, edge ids, resource ids). |
