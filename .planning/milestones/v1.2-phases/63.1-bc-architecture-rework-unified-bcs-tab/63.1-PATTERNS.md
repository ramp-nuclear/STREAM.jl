## Net-new Patterns (no analog — build from scratch)

### 1. `gui/src/lib/selectors/` directory and the selector-derived validator pattern

`gui/src/` has no `lib/selectors/` directory today. Memoized derived-state selectors as standalone pure modules are not an established pattern — Phase 63's bug class motivates introducing the pattern. Closest existing idiom is the inline `useCallback`-wrapped selector at `StreamNode.tsx:79-90` (primitive return + stable closure), which is the **consumer** side. There is no pure-function library mirror.

**Planner guidance:** Build `gui/src/lib/selectors/nodeErrors.ts` as a pure module that imports only types — no zustand, no React, no @xyflow runtime. Mirror the purity discipline already used by `gui/src/lib/codeGenerator.ts` (no React/store imports — `codeGenerator.ts:25-32` comment block is the explicit precedent for "pure, types-only inputs"). Consumers wrap in `useStore(useCallback(s => selectNodeErrors(s, id).length > 0, [id]))` returning a primitive — see Pattern 4 below for the consumer excerpt.

### 2. Memoized selector with primitive return for re-render avoidance

Project does not use `reselect`, `zustand/shallow`, or `useShallow` anywhere. The proven pattern is `useStore(useCallback(...))` returning a **primitive** (boolean/number/string). Multiple bits of derived state require multiple selector hooks — see `StreamNode.tsx:79-91` for three separate selectors in one component. This is the entire memoization story for the project.

## Shared Patterns

### Pattern A: Snapshot-before-mutate undo discipline

**Source:** `useStore.ts:1108-1114` (Phase 63 header comment) and applied throughout every action in the file.

**Apply to:** Every new store action in 63.1 (`setAnchor`, `clearAnchor`, `promoteToSharedSource`, and the rewritten `setBCSymmetric`).

**Excerpt:**
```ts
// Every BC mutation MUST call _pushSnapshot() BEFORE set(...) — mirrors the
// Phase 62 Resources slice discipline. `_revertBCModeForEdge` is the lone
// exception (called from onEdgesChange which already pushed a snapshot).
```
Concrete shape (from `setBCMode` at `useStore.ts:1116-1118`):
```ts
setBCMode: (componentId, externalInputName, entry) => {
  get()._pushSnapshot();
  const state = get();
  // ... compute next, then set(...)
},
```

### Pattern B: Immutable Record-of-keyed-records update

**Source:** `useStore.ts:1240-1242` (`clearBCMode`), `useStore.ts:1129-1135` (`setBCMode`), `useStore.ts:1402-1407` (`addGeometry`).

**Apply to:** `setAnchor`, `clearAnchor`, and any new Record-keyed mutation.

**Excerpt — set:**
```ts
const nextBCMode: Record<string, BCModeEntry> = {
  ...state.bcMode,
  [key]: entry,
};
```
**Excerpt — delete:**
```ts
const nextBCMode: Record<string, BCModeEntry> = { ...state.bcMode };
delete nextBCMode[key];
```

### Pattern C: Pure-module purity rule (no React, no zustand, no @xyflow runtime)

**Source:** `bcMode.ts:1-13` (module header), `codeGenerator.ts:25-32` (sentinel duplication comment), `validation.ts:73-78` ("Pure function — no side effects, no store dependency.").

**Apply to:** New files `gui/src/lib/anchors.ts`, `gui/src/lib/selectors/nodeErrors.ts`. Both must import only TS types from other modules — no runtime imports from `store/` or `@xyflow/react` (type-only imports are OK).

### Pattern D: Primitive-return selector via `useStore(useCallback(...))`

**Source:** `StreamNode.tsx:77-91` (three selector hooks, all primitive returns).

**Apply to:** All `StreamNode` consumers of the new `selectNodeErrors` selector and the new `anchors` slice. Never return a fresh array/object from a selector hook — split into multiple primitive selectors.

**Excerpt:**
```ts
const hasBCError = useStore(
  useCallback(
    (s: { errorTagsByNodeId: Record<string, string[]> }) =>
      (s.errorTagsByNodeId[id]?.length ?? 0) > 0,
    [id],
  ),
);
```
Anti-pattern (banned) — see Pitfall 1 in RESEARCH:
```ts
// ❌ Returns fresh array → infinite re-render loop
const errors = useStore((s) => selectNodeErrors(s, id));
```

**Source:** `SidebarPanel.tsx:323`, `BCsTabForm.tsx:271-273` (per-group header — same className).

**Apply to:** `AnchorsSection` header, `External Inputs` header (inside `SidebarPanel.ComponentTabs` `<TabsContent value="bcs">`).
