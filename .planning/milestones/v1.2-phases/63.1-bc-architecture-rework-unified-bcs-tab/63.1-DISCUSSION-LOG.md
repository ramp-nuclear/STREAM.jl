## Anchor data path (Q2)

| Option | Description | Selected |
|--------|-------------|----------|
| Per-component, on the bcMode dict with a reserved key | Single state shape; conflates anchors with external_inputs semantically | |
| Separate `anchors[]` slice; render rows in tab | Smallest delta from existing `bcs: BCEntry[]` shape | |
| Per-component, distinct shape `anchors: Record<nodeId, AnchorEntry>` | Clean separation matching the tab's two-section structure | ✓ (Claude's choice — user delegated) |

**User's choice:** "Whatever you think is best suited for the rework."
**Notes:** Claude chose Option 3 — distinct `Record<nodeId, AnchorEntry>` slice. Rationale: anchors are semantically different from external_inputs (scalar, structural, port-scoped vs. vector-valued 5-mode bindings); the Record shape enforces per-component uniqueness naturally; legacy `bcs[]` slice + freestanding BCPanel get deleted. See CONTEXT.md D-02..D-05.

## n-mismatch ring lifecycle / validator architecture (Q6)

| Option | Description | Selected |
|--------|-------------|----------|
| Event-driven — validator runs on specific mutations | Predictable cost; must enumerate every triggering mutation | |
| Store-mutation-driven — validator runs on every store mutation | Cannot stale-out; needs throttling | |
| Selector-derived — ring state is a computed selector, not stored | No possible staleness; selector always live; one computation path | ✓ (Claude's choice — user delegated) |

**User's choice:** "I really don't understand this. Do what you really think is the best and will give the best outcome handling all edge cases."
**Notes:** Claude chose Option 3 — selector-derived. Rationale: CR-03, the n-mismatch ring-stale bug, and the click-vs-drag stale-Properties bug all share one root cause (stored derived state going stale). Selector-derived eliminates the entire bug class by construction. Graph sizes in STREAM Composer are small; memoized recompute is trivial. Phase 71 validation framework can extend the same pattern. See CONTEXT.md D-15..D-19.
