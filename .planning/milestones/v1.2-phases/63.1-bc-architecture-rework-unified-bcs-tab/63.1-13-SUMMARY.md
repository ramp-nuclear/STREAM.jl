## Decisions Made

1. **Anchor glyph sizing: `w-3 h-3` (12 px).** Doubled from the previous 6-px dot. Larger to read as an anchor pictogram rather than a marker dot, but small enough not to dominate the FlowPort handle (which is also 12 px). Offsets bumped accordingly so the icon sits tangent to the handle on all four sides.

2. **Disabled-gate via `aria-disabled` (Radix Select default).** The `SelectItem` `disabled` prop produces both keyboard non-selectability AND `aria-disabled="true"` on the rendered option. Tests assert the latter directly. No explicit tooltip-on-disabled at this step (deferred to Phase 72 polish).

3. **Default seeds: `T_wall = 300.0`, `q = 0.0`.** Physically benign neutrals — 300 K is room temperature (clearly a placeholder, not a "hot fuel" assumption); 0 W/m² is "no source" (matches Channel's `h_left`/`h_right` registry default). The user can override immediately via Properties (Plan 11 RC-1 closure).

4. **`size="icon"` shadcn Button variant exists in the local cva.** Confirmed in `gui/src/components/ui/button.tsx:28` (`icon: "size-9"`). No fallback to `size="sm" + className="px-2"` needed.

5. **UI-SPEC deviation recorded.** §"Promote-to-Shared-Source Button" line 324 specified "literal `↗` Unicode" as load-bearing. Plan 13 reverses that decision under explicit user UAT authorization; UI-SPEC updated in this commit to reflect the new contract (one-line edit, no other paragraphs touched).
