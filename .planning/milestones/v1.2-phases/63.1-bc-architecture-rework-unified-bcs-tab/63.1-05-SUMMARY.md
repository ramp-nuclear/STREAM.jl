# Phase 63.1 Plan 05: Delete BCPanel/BCRow + BottomPanel BCs tab Summary

Wave 2 part C — completes D-03 "single rendering site" by physically
removing the freestanding `BCPanel.tsx` (the transitional anchors-driven
shim Plan 03 kept alive) along with its sole consumer `BCRow.tsx`, and
drops the BCs tab from `BottomPanel.tsx`. No anchor data path runs
through any of these files anymore — the new home is the per-component
right-sidebar BCs tab (Plan 06 lands AnchorsSection there). Pure
deletion + one tab removal; ran in parallel with Plan 04 because the
file sets are disjoint.

## What Was Built

### Task 1 — Delete legacy BC surface (commit 0160d93)

**Files deleted:**
- `gui/src/components/BCPanel.tsx` — the bottom-panel "BCs" form
  component. Plan 03 rewired its body to `anchors / setAnchor /
  clearAnchor` as a transitional shim; Plan 05 deletes it outright.
- `gui/src/components/BCRow.tsx` — chip-list row rendered by
  BCPanel. Was the only consumer; standalone after BCPanel deletion is
  meaningless, so deleted in the same commit.

**`gui/src/components/BottomPanel.tsx` edits** (lines 5, 26-28, 33-35):
- REMOVE `import BCPanel from "./BCPanel"` (line 5).
- REMOVE the `<TabsTrigger value="bcs" ...>BCs</TabsTrigger>` line.
- REMOVE the entire `<TabsContent value="bcs" ...><BCPanel /></TabsContent>` block.

Result: `BottomPanel` renders a single `Code` tab. The
`<Tabs defaultValue="code">` wrapper is kept (decision above —
RESEARCH §866-867 acceptable, minimizes churn, leaves room for future
bottom-panel tabs).

Final shape (29 lines):
```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "./ui/tabs";
import useStore from "../store/useStore";
import { useBottomPanelResize } from "../hooks/useBottomPanelResize";
import CodePreview from "./CodePreview";

export default function BottomPanel() {
  const bottomPanelOpen = useStore((s) => s.bottomPanelOpen);
  const bottomPanelHeight = useStore((s) => s.bottomPanelHeight);
  const { onMouseDown } = useBottomPanelResize();

  if (!bottomPanelOpen) return null;

  return (
    <div style={{ height: bottomPanelHeight }} className="border-t flex flex-col">
      <div
        className="h-2 w-full cursor-row-resize hover:bg-ring/30 transition-colors flex-shrink-0"
        onMouseDown={onMouseDown}
      />
      <Tabs defaultValue="code" className="flex-1 min-h-0 flex flex-col">
        <TabsList className="mx-2 mt-1">
          <TabsTrigger value="code" className="text-[13px] font-medium">
            Code
          </TabsTrigger>
        </TabsList>
        <TabsContent value="code" className="flex-1 min-h-0">
          <CodePreview />
        </TabsContent>
      </Tabs>
    </div>
  );
}
```
