**Fix 2 — VAL-01 Fourier in test/test_validation.jl:**

In the "VAL-01: HeatDiffusion transient — Fourier series validation" testset, change the solve call (line ~364):

From:
```julia
sol_v01 = solve(prob_v01, Rodas5P(); initializealg=SciMLBase.NoInit(),
                reltol=1e-6, abstol=1e-8, saveat=t_checkpoints)
```

To:
```julia
sol_v01 = solve(prob_v01, Rodas5P();
                reltol=1e-8, abstol=1e-10, saveat=t_checkpoints)
```

Rationale: This system is a pure ODE (HeatDiffusion + ConstantTemperature — no algebraic variables). NoInit is documented as causing inaccurate first adaptive steps for ODEs; removing it allows the default consistent initialization to run. Tightened tolerances (1e-8/1e-10) ensure the 1% assertion holds at the early t=0.5*tau checkpoint where the plate is in steep transient. The `warn_initialize_determined=false` kwarg stays on the ODEProblem constructor — do not remove it.

Do NOT change VAL-02 (transient T_outlet step) — it legitimately uses NoInit for a mixed ODE/parameter system.

```yaml
name: CI
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.ref != 'refs/heads/main' }}
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: julia-actions/setup-julia@v2
        with:
          version: '1'
      - uses: julia-actions/cache@v2
      - uses: julia-actions/julia-buildpkg@v1
      - uses: julia-actions/julia-runtest@v1
```

Create the directory `.github/workflows/` first if it does not exist.

Notes:
- `version: '1'` pins to Julia stable (D-12 — no multi-version matrix)
- `ubuntu-latest` only (D-12 — no macOS/Windows matrix)
- No codecov or branch protection (D-14)
- `concurrency` block cancels stale PR runs without affecting main branch pushes
