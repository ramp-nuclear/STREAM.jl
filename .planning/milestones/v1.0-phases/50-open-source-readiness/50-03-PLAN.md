3. **Parameters section**:
   ```julia
   const NZ        = 10        # axial cells
   const NX        = 3         # lateral cells in plate
   const T_INLET   = 313.15    # K (40°C)
   const DP_PUMP   = 3.0e4     # Pa
   const POWER     = 1.0e4     # W total fission power
   # MTR plate geometry (rectangular channel)
   const L_PLATE   = 0.6       # m axial length
   const Y_PLATE   = 0.07      # m plate half-width (heated perimeter)
   const LX_PLATE  = 0.00127   # m plate thickness
   # Aluminum plate material
   const RHO_AL    = 2700.0    # kg/m³
   const CP_AL     = 900.0     # J/(kg·K)
   const K_AL      = 200.0     # W/(m·K)
   ```

4. **Assembly** — explicit step-by-step to teach the pattern:

   ```julia
   println("Building MTR assembly...")

   # Step 1: Define rectangular channel geometry (per CLAUDE.md: PipeGeometry_rectangular)
   geom = PipeGeometry_rectangular(L_PLATE, Y_PLATE, LX_PLATE, Y_PLATE)

   # Step 2: Fuel plate with uniform power shape
   ps = fill(1.0 / (NZ * NX), NZ, NX)
   @named fuel = HeatDiffusion(nz=NZ, nx=NX, Lz=L_PLATE, Lx=LX_PLATE, y=Y_PLATE,
                                rho_s=RHO_AL, cp_s=CP_AL, k_s=K_AL,
                                power_shape=ps, power=POWER)

   # Step 3: Left and right coolant channels
   @named cac_l = ChannelAndContacts(n=NZ, geometry=geom)
   @named cac_r = ChannelAndContacts(n=NZ, geometry=geom)

   # Step 4: Thermal coupling via symmetric_plate
   # symmetric_plate(left_channel, right_channel, fuel; name) wires thermal_left and thermal_right
   @named rods = symmetric_plate(cac_l, cac_r, fuel)

   # Step 5: Complete loops with pumps and heat exchangers
   @named pump_l = Pump(DP_PUMP)
   @named hx_l   = HeatExchanger(T_INLET)
   @named pump_r = Pump(DP_PUMP)
   @named hx_r   = HeatExchanger(T_INLET)

   conns = [
       connect(pump_l.outlet, hx_l.inlet),
       connect(hx_l.outlet, port(rods, :cac_l, :inlet)),
       connect(port(rods, :cac_l, :outlet), pump_l.inlet),
       pump_l.inlet.P ~ 1.0e5,
       connect(pump_r.outlet, hx_r.inlet),
       connect(hx_r.outlet, port(rods, :cac_r, :inlet)),
       connect(port(rods, :cac_r, :outlet), pump_r.inlet),
       pump_r.inlet.P ~ 1.0e5,
   ]
   @named sys = compose(System(conns, t; name=:mtr_example), pump_l, hx_l, pump_r, hx_r, rods)
   ssys = mtkcompile(sys; fully_determined=false)
   ```

   NOTE: If `symmetric_plate` usage differs from the above (e.g., different port accessor pattern), read `src/composition/helpers.jl` to confirm the exact call signature and adjust accordingly. The test_validation.jl VAL-01 MTR test (lines 71-155) shows the raw approach; use symmetric_plate if it's the higher-level helper.
