### FLAP-05: Flapper remains closed under positive ref_mdot

Build a minimal transient system where ref_mdot is always above threshold. The test must prove near-zero leakage through the Flapper path.

Test strategy:
- Create a simple system: Pump (scalar, e.g. 1e5 Pa) -> Resistor (or Channel) -> back to Pump, with a Flapper in a parallel bypass path.
- Wire `flapper.ref_mdot ~ pump.port_in.mdot` (or any component with positive mdot) so ref_mdot stays well above the Flapper's threshold (default 0.01 kg/s).
- Run `solve_transient` for a short period (e.g. 0-10s).
- Assert that `T_open` remains at the sentinel value 1e30 (event never fired).
- Assert that flow through the Flapper path is near zero (resistance is R_closed = 1e8, so mdot through flapper ~ dP/R_closed ~ negligible).

Alternative simpler approach if parallel paths are complex: Create a standalone Flapper system (not a full loop) that can be compiled and run in isolation:
- Flapper + Pump in series, with ref_mdot wired to a positive-valued reference.
- Pin pressure at one end, pin mdot at the other.
- Verify T_open stays at 1e30 after solve.

The executor should choose the simplest viable approach. The key assertion is: `sol[ssys.flapper.T_open]` at end time equals 1e30 (or within tolerance), proving the event never fired.

```julia
@testset "FLAP-05: Flapper remains closed under positive ref_mdot" begin

    @test sol.retcode == ReturnCode.Success
```

### FLAP-06: Flapper opens when ref_mdot crosses threshold

Build a transient system where a callable pump ramps pressure from a positive value to zero, causing mdot to decrease and eventually cross the Flapper threshold.

Test strategy:
- Use Pump(dP_pump_fn) with a callable that ramps from 1e5 to 0 over ~50s: `dP(t) = max(1e5 * (1 - t/50), 0)`.
- Wire `flapper.ref_mdot ~ pump.port_in.mdot` (or the appropriate component's mdot).
- Run `solve_transient` for 0-100s (enough for pump to reach zero and mdot to decay below threshold).
- Assert that `T_open` is recorded at a time between 0 and 100 (event fired).
- Assert that `T_open` is NOT 1e30 (event actually fired).
- After `T_open + dt`, verify the ramp has completed: the effective resistance should be near R_open (100.0).
- Check the Hermite ramp shape: at `T_open + dt/2`, xi should be ~0.5, and `3*(0.5)^2 - 2*(0.5)^3 = 0.5`, so R_eff ~ (R_closed + R_open)/2 approximately (though exact depends on the interpolation -- actually 0.5 Hermite gives 0.5, so R_eff = R_closed + (R_open - R_closed)*0.5).
