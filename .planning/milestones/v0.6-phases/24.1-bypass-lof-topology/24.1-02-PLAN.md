**Header and imports:**
```julia
using Test
using ModelingToolkit
```

**File-level comment block** explaining:
- Bypass topology: 4-node network with parallel paths (channel vs flapper shortcut)
- Node layout: A (top, pump outlet), B (bottom, U-turn), C (top, flapper junction), D (pump inlet)
- Gravity: ch (downward, g=-9.80665), ret (upward, g=+9.80665)
- IC strategy: reference loop without Flapper/Inertia for KINSOL SS, then transfer to bypass system
- Energy balance formula: `Q_meas = |mdot| * cp * |T_max_cells - T_inlet|`

**Constants:**
```julia
const BYPASS_N        = 10
const BYPASS_L_CH     = 1.0
const BYPASS_D_CH     = 0.01
const BYPASS_T_WALL   = 373.15
const BYPASS_T_INLET  = 313.15
const BYPASS_G_ACC    = 9.80665
const BYPASS_L_OVER_A = 1.75e5
const BYPASS_R_EXT    = 1.0e6
const BYPASS_THRESHOLD = 0.01
const BYPASS_DT_RAMP  = 5.0
const BYPASS_DP_REF   = 1.5e4    # reference pump dP for SS IC generation
```

**IC helper function `_lof_bypass_ic`:**
1. Build a reference forced-flow loop to get SS values. The reference loop must match the bypass topology's heated channel but without Flapper/Inertia (KINSOL-friendly). Use:
   - `@named pump_ref = Pump(BYPASS_DP_REF)`
   - `@named hx_ref = HeatExchanger(T_bc=BYPASS_T_INLET)`
   - `@named ch_ref = ChannelHeatFlux(n=n, geometry=PipeGeometry_circular(BYPASS_L_CH, BYPASS_D_CH), g=-BYPASS_G_ACC, T_wall=BYPASS_T_WALL)`
   Note: `g=-BYPASS_G_ACC` for downward channel (same as bypass topology).
   Wire: `pump_ref -> hx_ref -> ch_ref -> pump_ref`, plus `pump_ref.port_in.P ~ 1.0e5`, `ch_ref.port_in.T ~ BYPASS_T_INLET`.
   Compile with `mtkcompile(ref_sys)`.
   IC guess: `ref_ssys.ch_ref.port_in.mdot => 0.1`, linearly interpolated T cells.
   Solve with `solve_steady(ref_ssys, op_ref)`.
   Extract `mdot_ss` and `T_ss[1:n]`.

2. Build bypass system: `build_loop_lof_bypass(; n=n, L_ch=BYPASS_L_CH, D_ch=BYPASS_D_CH, T_wall=BYPASS_T_WALL, T_inlet=BYPASS_T_INLET, L_over_A=BYPASS_L_OVER_A, g_acc=BYPASS_G_ACC, R_ext=BYPASS_R_EXT, threshold=BYPASS_THRESHOLD, dt_ramp=BYPASS_DT_RAMP)`.

3. Build IC op vector:
   ```julia
   op = Pair{Any,Any}[
       ssys.ine.port_in.mdot => mdot_ss,
       ssys.flapper.T_open   => 1.0e30,
   ]
   for i in 1:n
       push!(op, ssys.ch.T[i] => T_ss[i])
   end
   for i in 1:n
       push!(op, ssys.ret.T[i] => BYPASS_T_INLET)
   end
   ```

4. Return `(ssys, op, mdot_ss)`.

  ```julia
  mdot_v  = abs(sol[ssys.ch.port_in.mdot, idx])
  ```

**Test: VAL-02** ("VAL-02: NC equilibrium mdot within 20% of analytical estimate"):
- Use last 10% of 300 s run (indices 2701:3001, t=270..300 s)
- Average NC channel mdot: `mdot_nc = mean(abs.(sol[ssys.ch.port_in.mdot, 2701:3001]))`
- Average NC channel max T: `T_max_nc = mean([maximum([sol[ssys.ch.T[i], idx] for i in 1:BYPASS_N]) for idx in 2701:3001])`
- Compute analytical NC estimate:
  ```julia
  geom = PipeGeometry_circular(BYPASS_L_CH, BYPASS_D_CH)
  A_xs = geom.A
  Dh   = geom.Dh
  T_hot_avg = (BYPASS_T_INLET + T_max_nc) / 2
  rho_cold = rho_water(BYPASS_T_INLET)
  rho_hot  = rho_water(T_hot_avg)
  delta_rho = rho_cold - rho_hot
  # Blasius friction at NC Re (use measured NC mdot for Re)
  Re_nc = mdot_nc * Dh / (A_xs * mu_water(T_hot_avg))
  f_nc  = 0.316 * Re_nc^(-0.25)   # Blasius
  # Analytical: buoyancy = friction => mdot ~ sqrt(delta_rho * g * H * 2 * rho_hot * A^2 * Dh / (f * L))
  mdot_analytical = sqrt(delta_rho * BYPASS_G_ACC * BYPASS_L_CH * 2 * rho_hot * A_xs^2 * Dh / (f_nc * BYPASS_L_CH))
  ```
- `@test isapprox(mdot_nc, mdot_analytical; rtol=0.20)`
- If the 20% tolerance is too tight due to the external resistance term or return-pipe friction not being in the analytical formula, widen to 30% and add a comment explaining why.
