## Milestone Summary

**Key Decisions:**

- Fresh RFC 4122 UUID via `uuidgen` (not placeholder reuse)
- PackageCompiler to [extras] only — prevents LLVM as transitive runtime dep
- CI: Julia stable only, ubuntu-latest only — no multi-version matrix
- THRESHOLD_MB=6144 (6 GB) RAM gate — conservative for PackageCompiler link step
- Sysimage bakes STREAM+QuadGK only (MTK/ODE/Sundials excluded — LLVM IR OOM on 32 GB WSL2)
- Persistent REPL + Revise.jl as primary development workflow (sysimage unreliable on Julia1.12+WSL2)

**Issues Resolved:**

- NET-03 Cube flow test: switched to RobustMultiNewton with expanded 12-variable initial guess
- VAL-01 Fourier series test: removed NoInit from pure ODE solves, tightened tolerances to 1e-8/1e-10
- MTR assembly power equation: HeatDiffusion power is MTK @variables unknown (not a parameter) — `rods.hd.power ~ POWER` governing equation required
- test/Project.toml added for direct `julia --project=. test/runtests.jl` invocation

**Issues Deferred:**

- Sysimage on Julia 1.12 + WSL2 (TTFX-04): PackageCompiler incremental link killed by SIGTERM at ~7min regardless of package list; build infrastructure retained for future Julia versions

**Technical Debt:**
- None introduced in this milestone (all workarounds are documented, not buried)
