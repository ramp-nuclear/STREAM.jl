**If any CONN tests FAIL:** Read the current src/connectors.jl and diagnose. The most common failure modes are:

1. **`VariableConnectType` returns wrong type for mdot or T:** The `[connect = Flow]` or `[connect = Stream]` annotation is missing or misspelled in the @connector block. The correct syntax for MTK v11:

```julia
@connector FlowPort begin
    P(t) = 1.0e5, [description = "Pressure (Pa), across variable"]
    mdot(t) = 0.0, [connect = Flow, description = "Mass flow rate (kg/s), positive = into port"]
    T(t) = 300.0, [connect = Stream, description = "Temperature (K), stream variable"]
end
```

2. **`t` variable conflict:** If the file uses `@variables t` instead of `using ModelingToolkit: t_nounits as t`, the connector's time variable will not be MTK's canonical `t`. Fix: replace any `@variables t` with `using ModelingToolkit: t_nounits as t`.

3. **`ThermalPort.T` incorrectly tagged as Flow:** T in ThermalPort must be an across variable — no `[connect = ...]` annotation. The test expects `VariableConnectType(T) == ModelingToolkit.Equality`.

The correct final src/connectors.jl content (write this if fixes are needed):

```julia
# MTK connectors for STREAM.jl thermal-hydraulic system
# Both connectors use the @connector macro (MTK v9+ API).
# Do NOT use the old function-based connector style.

using ModelingToolkit
using ModelingToolkit: t_nounits as t

"""
FlowPort — hydraulic flow connector.

Variables:
- P(t):    pressure in Pa (across variable — same value at connected ports)
- mdot(t): mass flow rate in kg/s (Flow variable — sums to zero at junction)
             Sign convention: positive = into port (MTK Kirchhoff convention)
- T(t):    temperature in K (Stream variable — upwinding: follows flow direction)
             Use instream(port.T) in component equations, not port.T directly.
"""
@connector FlowPort begin
    P(t)    = 1.0e5, [description = "Pressure (Pa), across variable"]
    mdot(t) = 0.0,   [connect = Flow,   description = "Mass flow rate (kg/s), positive = into port"]
    T(t)    = 300.0, [connect = Stream, description = "Temperature (K), stream variable"]
end

"""
ThermalPort — thermal connector.

Variables:
- T(t):      temperature in K (across variable — same value at connected ports)
- Q_flow(t): heat flow rate in W (Flow variable — sums to zero at junction)
               Sign convention: positive = into component

Mirrors ModelingToolkitStandardLibrary's HeatPort design.
"""
@connector ThermalPort begin
    T(t)      = 300.0, [description = "Temperature (K), across variable"]
    Q_flow(t) = 0.0,   [connect = Flow, description = "Heat flow rate (W), positive = into component"]
end
```
