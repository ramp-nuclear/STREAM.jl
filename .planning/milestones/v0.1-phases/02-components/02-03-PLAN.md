
Locked parameter signatures (CONTEXT.md):
- Pump(; name, dP)               # dP: Pa, constant pressure rise
- Friction(; name, L, D, A)      # L: m, D: m, A: m²
- Gravity(; name, H, A)          # H: m height, A: m²

Physics (from Python STREAM source, verified in RESEARCH.md):

Pump:
- port_out.P - port_in.P ~ dP   (pressure rise)
- port_in.mdot + port_out.mdot ~ 0   (mass continuity)
- port_out.T ~ instream(port_in.T)   (isenthalpic — temperature unchanged)
- port_in.T  ~ instream(port_out.T)  (required structurally)

Friction:
- Re ~ abs(port_in.mdot) * D / (A * mu_water(instream(port_in.T)))
- f  ~ 0.3164 * Re^(-0.25)   (Blasius, valid Re < 100000)
- port_in.P - port_out.P ~ f * (port_in.mdot * abs(port_in.mdot) /
                                (2 * rho_water(instream(port_in.T)) * A^2)) * (L / D)
  (Darcy-Weisbach; positive when flow is in positive mdot direction)
- port_in.mdot + port_out.mdot ~ 0
- port_out.T ~ instream(port_in.T)
- port_in.T  ~ instream(port_out.T)

Gravity:
- port_in.P - port_out.P ~ rho_water(instream(port_in.T)) * 9.80665 * H
  (pressure drops when flowing upward through height H; convention: port_in below port_out)
- port_in.mdot + port_out.mdot ~ 0
- port_out.T ~ instream(port_in.T)
- port_in.T  ~ instream(port_out.T)

Locked observable declarations (CONTEXT.md):
- Friction exposes Re and f as MTK @variables (appear in observed after mtkcompile)
- Pump: no additional observables beyond port variables
- Gravity: no additional observables beyond port variables

Variable initial guesses (physics-based, CONTEXT.md):
- T = 600.0 (K), P = 1.0e5 (Pa), mdot = 1.0 (kg/s) as defaults in FlowPort
- Re, f: no initial guesses (algebraic, solved from mdot at t=0)

Pump implementation:
```julia
function Pump(; name, dP)
    pars = @parameters begin
        dP_pump = dP
    end
    @named port_in  = FlowPort()
    @named port_out = FlowPort()
    eqs = Equation[
        port_in.mdot + port_out.mdot ~ 0,
        port_out.P - port_in.P ~ dP_pump,
        port_out.T ~ instream(port_in.T),
        port_in.T  ~ instream(port_out.T),
    ]
    compose(System(eqs, t, [], pars; name=name), port_in, port_out)
end
```

Friction implementation:
```julia
function Friction(; name, L, D, A)
    pars = @parameters begin
        L_f = L
        D_h = D
        A_f = A
    end
    vars = @variables begin
        Re(t)
        f(t)
    end
    @named port_in  = FlowPort()
    @named port_out = FlowPort()
    T_in = instream(port_in.T)
    eqs = Equation[
        port_in.mdot + port_out.mdot ~ 0,
        Re ~ abs(port_in.mdot) * D / (A * mu_water(T_in)),
        f  ~ 0.3164 * Re^(-0.25),
        port_in.P - port_out.P ~ f * (port_in.mdot * abs(port_in.mdot) /
                                       (2 * rho_water(T_in) * A^2)) * (L / D),
        port_out.T ~ instream(port_in.T),
        port_in.T  ~ instream(port_out.T),
    ]
    compose(System(eqs, t, vars, pars; name=name), port_in, port_out)
end
```
