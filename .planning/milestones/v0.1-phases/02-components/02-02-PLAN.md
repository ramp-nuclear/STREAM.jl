Locked decisions (CONTEXT.md — NON-NEGOTIABLE):
- Single ThermalPort, total Q_wall. Internal: q_wall[i] ~ thermal.Q_flow / n
- instream(port_in.T) for inlet temperature (cell 1 upstream boundary)
- T_in[i] = T[i-1] for cells 2..n (first-order upwind, direct variable reference)
- Observable variables as MTK @variables: Re[i], Nu[i], h_tc[i], v[i], T_out, dP
- No initial guesses for algebraic vars (Re, Nu, h_tc, v, dP, q_wall)
- T initial guess = 600.0 K, P = 1.0e5 Pa, mdot = 1.0 kg/s
- n is a plain Julia Int (NOT an MTK @parameters entry — would break for-loop)

Physics (from Python STREAM source, verified):
- Re = |mdot| * D / (A * mu_water(T[i]))
- Pr = cp_water(T[i]) * mu_water(T[i]) / k_water(T[i])
- Nu = 0.023 * Re^0.8 * Pr^0.4    (Dittus-Boelter, heating)
- h_tc = Nu * k_water(T[i]) / D
- v = mdot / (rho_water(T[i]) * A)
- Energy balance (first-order upwind FV):
    D(T[i]) ~ (mdot * cp_water(T[i]) * (T_up - T[i])
               + h_tc[i] * (pi * D) * dz * (thermal.T - T[i]))
              / (rho_water(T[i]) * cp_water(T[i]) * A * dz)
  where dz = L / n, T_up = instream(port_in.T) if i==1, else T[i-1]
- dP (scalar, algebraic, Darcy-Weisbach with mean conditions):
    f_ch = 0.3164 * Re_mean^(-0.25)   # Blasius, Re_mean computed at mean T
    dP ~ f_ch * (mdot * abs(mdot) / (2 * rho_water(T_mean) * A^2)) * (L / D)
  Use T[n÷2 + 1] as T_mean proxy (middle cell), or use T[1] — Claude's discretion.
  This is a single scalar observable (not per-cell), matching Python STREAM ChannelVar.pressure_drop.

Stream variable wiring (from stream_connectors.jl AdiabaticStraightPipe pattern):
- port_out.T ~ T[n]           # component sets outflow stream value
- port_in.T  ~ instream(port_out.T)  # structurally required (identity here)
- port_in.mdot + port_out.mdot ~ 0   # mass continuity
- port_out.P - port_in.P ~ -dP       # pressure drops in flow direction (port_in.P > port_out.P)
  Note: dP is positive value; pressure decreases in flow direction.
  Convention: port_in has higher pressure (flow enters high-P end).

Implementation structure:

```julia
function Channel(; name, n::Int, L, D, A)
    pars = @parameters begin
        L_ch = L
        D_h  = D
        A_ch = A
    end

    vars = @variables begin
        (T(t))[1:n]      = fill(600.0, n)
        (Re(t))[1:n]
        (Nu(t))[1:n]
        (h_tc(t))[1:n]
        (v(t))[1:n]
        (q_wall(t))[1:n]
        T_out(t) = 600.0
        dP(t)
    end

    @named port_in  = FlowPort()
    @named port_out = FlowPort()
    @named thermal  = ThermalPort()

    dz = L / n

    eqs = Equation[]
    T_inlet = instream(port_in.T)

    for i in 1:n
        T_up = (i == 1) ? T_inlet : T[i-1]
        # Energy balance (first-order upwind FV)
        push!(eqs,
            D(T[i]) ~ (port_in.mdot * cp_water(T[i]) * (T_up - T[i])
                       + h_tc[i] * (π * D) * dz * (thermal.T - T[i]))
                      / (rho_water(T[i]) * cp_water(T[i]) * A * dz)
        )
        # Observables
        push!(eqs, q_wall[i] ~ thermal.Q_flow / n)
        push!(eqs, v[i]      ~ port_in.mdot / (rho_water(T[i]) * A))
        push!(eqs, Re[i]     ~ abs(port_in.mdot) * D / (A * mu_water(T[i])))
        push!(eqs, Nu[i]     ~ 0.023 * Re[i]^0.8 *
                                (cp_water(T[i]) * mu_water(T[i]) / k_water(T[i]))^0.4)
        push!(eqs, h_tc[i]  ~ Nu[i] * k_water(T[i]) / D)
    end

    # Scalar observables
    i_mid = max(1, n ÷ 2)   # middle cell for mean-property dP
    Re_mean = abs(port_in.mdot) * D / (A * mu_water(T[i_mid]))
    f_ch    = 0.3164 * Re_mean^(-0.25)
    push!(eqs, T_out ~ T[n])
    push!(eqs, dP    ~ f_ch * (port_in.mdot * abs(port_in.mdot) /
                                (2 * rho_water(T[i_mid]) * A^2)) * (L / D))

    # Port wiring
    push!(eqs, port_in.mdot + port_out.mdot ~ 0)
    push!(eqs, port_out.P - port_in.P ~ -dP)
    push!(eqs, port_out.T ~ T[n])
    push!(eqs, port_in.T  ~ instream(port_out.T))

    all_vars = [collect(T); collect(Re); collect(Nu);
                collect(h_tc); collect(v); collect(q_wall);
                T_out; dP]

    compose(System(eqs, t, all_vars, pars; name=name), port_in, port_out, thermal)
end
```

Key points:
- `n` is used directly in the for-loop — it is a plain Julia Int, NOT an MTK @parameters (would fail with MethodError on `iterate`)
- Array variables splatted via `collect()` before passing to System() — avoids Symbolics.Arr dimension error (Pitfall 1 from RESEARCH.md)
- `instream(port_in.T)` used for inlet T, not `port_in.T` directly (Pitfall 2 note: fine in isolation test, MTK handles unresolved stream)
- `abs(port_in.mdot)` in Re expression — MTK handles symbolic abs correctly with ForwardDiff (per RESEARCH.md open question resolution)
- dP is purely algebraic (no D(dP) ~) — will appear in observed() after mtkcompile (Pitfall 4 from RESEARCH.md)
- The `instream()` function is available as `ModelingToolkit.instream` — if needed, add `using ModelingToolkit: instream` at top of components.jl or use the fully qualified name
