### Minor Gap (no REQ violation)

**PERS-01 nuance:** `reconstructInstanceCounters` only recovers counters for nodes following `prefix_N` naming. After a user renames a node (e.g., `core_channel`) and saves/reloads, the next drag of that component type restarts from `_1`, potentially producing a duplicate Julia identifier. Not a crash — but would cause Julia parse errors in the generated code. Affects users who rename components.

None. All registry exports, validation functions, and persistence utilities are consumed downstream.
